# 쟁점 문단 라이브러리 — 사용법

이 폴더의 문단 파일은 job 문서작성에서 **"📚 쟁점 문단"** 버튼으로 보고서에 끼워 넣는 표준 검토 문단입니다.
AI를 쓰지 않고(토큰 0) 사건 값으로 빈칸을 채워 넣고, 적용 조문 원문은 부록에 자동으로 붙습니다.
세무사님이 이 파일들을 직접 고치면 다음 보고서부터 고친 내용이 그대로 쓰입니다.
(파일 이름이 `_`로 시작하는 이 파일은 목록에 나오지 않습니다.)

## 파일 맨 위 머리말(지우지 마세요)

```
<!-- 문단정보
제목: 화면 목록에 보일 이름
세목: 양도 / 증여 / 상속 / 공통
추천: 사건분류·세액계산 결과에 이 낱말이 있으면 추천 목록 위로 (| 로 구분)
조문: 법령명 조번호 | 법령명 조번호   ← 부록에 원문이 자동으로 붙음
-->
```

## 빈칸 쓰는 법

- `{변수}` — 사건 값으로 자동 채움. 못 채우면 `⚠[확인필요: 변수]`로 남습니다.
- `{AI: 할 일}` — 사건마다 판단이 필요한 자리. `✍️[AI 작성: 할 일]`로 남고, AI 패널에 "빈칸 채워줘"라고 하면 이 자리만 씁니다.

## 자동으로 채워지는 변수

| 변수 | 내용 | 어디서 |
|---|---|---|
| {고객명} {사건명} {작성일} | 사건 기본정보 | 작업관리 |
| {기준일} | 양도일·증여일·상속개시일 | 사건 기준일 |
| {양도인} | 양도인 성명 | 사건개요서 |
| {소재지} {양도가액} {취득가액} {취득일} | 첫 번째 물건 | 사건개요서 물건목록 |
| {보유기간} | 취득일~기준일 | 계산 |
| {거주기간} | 주민등록초본 정리 결과의 해당 주소 거주기간 | 서류 자동정리(초본이 사건 폴더에 있을 때) |
| {증여자} {수증자} {관계} {증여가액} {인수채무} {기증여합산액} | 증여 사건개요 | 사건개요서 |
| {피상속인} {상속인} {상속인수} {상속재산가액} | 상속 사건개요 | 사건개요서 |
| {최종세액} | 세액계산 최근 저장값 | 세액계산 "이 사건에 저장" |
