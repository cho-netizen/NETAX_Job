# 개발자 → 세무사님 질문

웹 Claude Code 루틴(개발자)이 판단이 필요해 세무사님께 묻고 싶은 것을 여기에 남긴다. job 설정 🐞 카드 "❓ 개발자 질문"에 보이고, 세무사님 답은 다음 개선 후보 보고서(`answers`)에 실린다. 답을 반영했으면 그 블록을 지운다.

형식(꼭 지킬 것 — job이 이 모양으로 읽는다):

```
## Q-20261013-1 질문 제목(한 줄)
배경과 고를 수 있는 선택지를 쉬운 말로. 코드 용어는 쓰지 않는다. 고객 정보는 쓰지 않는다(저장소 공개).
```
