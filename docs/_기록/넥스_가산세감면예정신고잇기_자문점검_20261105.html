넥스 점검 246 — 「가산세 감면(국세기본법 §48) 계산기 — 수정신고·기한후신고 단계 율·달력 경계·연혁 확인과 예정신고분을 확정신고기한까지 고칠 때의 50%(§48②3호 다·라목) 잇기」 자문점검 · 2026-11-05

계산기(calculate_filing_penalty_reduction)를 열한 갈래로 돌려 §48①②를 맞췄습니다. 1호·2호 단계(90/75/50/30/20/10%, 50/30/20%)·달력 경계·경정 예지·2019년 연혁은 맞았으나, 양도세 예정신고분을 확정신고기한까지 수정·기한후신고하면 50%인 3호 다·라목이 없어 6개월이 지나면 30%·0%로 세던 것을 더했습니다.

1. 사건 (시험용 가정)

  • 2026년 3월 양도 예정신고(기한 5-31)를 과소신고한 사람이 2027-05-20 수정신고(11개월 반). 견주기: 1개월 안·넘김 / 기한후 6개월째·넘김 / 경정 예지 / 2019년 수정 / 예정신고 뒤 3개월 안(75%) / 예정 무신고 → 확정기한 안 기한후신고 / 확정기한 넘김 / 날짜 대신 flag.

2. 법 (원문을 직접 읽음 — 국세기본법 읽기용 판)

  • §48①: 기한 연장 사유·정당한 사유면 가산세 없음. ②1호: 기한 안 신고 뒤 수정신고(과소신고가산세만, 경정 예지 제외) — 1개월 90%, 3개월 75%, 6개월 50%, 1년 30%, 1년 6개월 20%, 2년 10%. 2호: 기한후신고(무신고가산세만) — 1개월 50%, 3개월 30%, 6개월 20%. 3호 다목: 1호 라~바목에도 불구하고 예정·중간신고를 했으나 과소신고한 것을 확정신고기한까지 수정신고하면 50%. 라목: 2호에도 불구하고 예정·중간신고를 안 했다가 확정신고기한까지 기한후신고하면 50%(경정 예지 제외). 가목(과세전적부심 지연)·나목(제출등 1개월 안)도 50%.

3. 도구가 놓치던 것

  • 단계·경계·연혁 맞음: 9-30 기한 → 10-31 수정 90%, 11-01 75% / 기한후 3-31 20%, 4-01 0 / 예지 0 / 2019년 5개월 50%.
  • 예정신고분(기한 2026-05-31)을 2027-05-20 수정 → 1호 라목 30%로만 셌다(법은 다목 50%). 예정 무신고를 확정기한 안 기한후신고 → 2호 6개월 넘어 0%로 셌다(법은 라목 50%).
