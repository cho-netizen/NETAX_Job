둘째 판에서 바뀐 것 — 첫째 판은 단추를 수금관리 줄에 달았습니다. 그 줄은 새벽 2시나 대시보드 「확인」을 누른 뒤에야 생겨서, 영수증을 저장한 바로 그때는 누를 단추가 없었습니다. 둘째 판은 단추가 폴더의 영수증 파일에서 시작하고, 보내는 순간 그 영수증을 수금관리에도 바로 기록합니다.

1. 목적

홈택스에서 발급해 「1 상담사건」 폴더에 PDF로 저장하신 현금영수증을, 넥스 화면에서 단추 하나로 고객 휴대폰에 사진 문자로 보내고, 같은 순간 수금관리에 기록한다.

2. 쓰시는 차례

홈택스 발급→「1 상담사건」에 PDF 저장→📱 영수증 문자→방금 저장한 파일 고르기(맨 위)→미리 보기 확인→보내기→문자 나감 + 수금관리 기록
  1. 단추 자리 — 대시보드 「최근수금」 카드의 「확인」 옆, 그리고 수금관리 화면 위쪽. 어느 화면에서든 한두 번에 닿는 자리입니다.
  2. 파일 목록 — 누르면 「1 상담사건」 폴더(하위 폴더 포함)의 현금영수증 PDF를 최근 저장한 것부터 보여 드립니다. 줄마다 고객명(파일 이름에서)·저장 시각·「보냄 11-25」 표시(이미 보낸 것). 방금 저장한 파일이 맨 위에 옵니다(드라이브가 파일을 알아채는 데 몇 초 걸릴 수 있어, 안 보이면 「다시 찾기」).
  3. 미리 보기 창 — 고르면 곧바로:
    • 영수증 첫 쪽을 그림으로 바꿔 크게(빈 여백은 잘라 냄)
    • 영수증에서 읽은 금액·날짜·발행처(지금 수금 인식과 같은 판독, 비용 0원)
    • 받는 번호 — 고객관리 전화번호 → 없으면 상담 예약 기록의 번호 → 그래도 없으면 입력칸 · 보낸 번호는 고객관리에 저절로 남김(빈 칸이면 전화번호에, 다른 번호가 있으면 추가연락처에, 없는 고객이면 새로 등록, 같은 이름이 여럿이면 남기지 않고 알림)
    • 보낼 글 기본값 「이음세무컨설팅에서 현금영수증을 보내드립니다. / 카카오채널로 편하게 상담하실 수 있습니다: https://pf.kakao.com/_SixeWn / 리뷰를 남겨 주시면 큰 힘이 됩니다. / 구글: https://maps.google.com/?cid=10498862036873431500 / 네이버: 네이버 지도 앱 MY플레이스에서 이 영수증 사진으로 인증 후 작성」(고칠 수 있음) · 「사진 문자 110원」
    • [보내기] [닫기]
  4. 보내기를 누르면 — ① 사진 문자 보냄 ② 성공하면 그 영수증을 수금관리에 바로 기록(사건 미연결·고객명으로 — 밤 작업이 하던 기록과 똑같은 모양) ③ 그 파일에 「기록함」 표시를 붙여 밤 작업·「확인」이 다시 세지 않게 ④ 상담 기록에 「문자 발송(현금영수증 사진)」 한 줄. 끝나면 「보냈습니다 · 수금 33,000원 기록」처럼 알려 드립니다.
  5. 문자가 실패하면 — 까닭(잔액·번호 틀림 등)을 그대로 보여 드리고 수금 기록도 하지 않습니다(다시 보내기 가능).
  6. 이미 수금에 기록된 영수증이면(밤 작업이 먼저 읽었거나 다시 보내는 경우) — 문자만 보내고 수금은 다시 적지 않습니다.

4. 솔라피 사진 문자 규격 (공식 프로그램 원본에서 확인)

  • 사진 올리기 storage/v1/files(그림 base64·종류 MMS) → 받은 번호로 지금 쓰는 보내기에 imageId·제목을 붙이면 사진 문자.
  • 사진 200KB까지, JPG로 만든다. 요금 110원/통(부가세 별도). 열쇠·발신번호는 지금 것 그대로.

자리할 일

7. 그림 영수증을 지우시기 전에 (세무사님 "현재 있는 그림영수증은 모두 삭제하겠다")

  • 주○○_현금영수증_1.jpg(09-09)는 짝이 되는 PDF가 없습니다. 같은 분의 PDF는 「주○○_현금영수증_2.pdf」로 이름 끝 숫자가 달라, 다른 영수증일 수 있습니다. 지우시기 전에 같은 영수증인지 한 번 봐 주십시오.
  • 전○○·유○○ PNG는 같은 이름의 PDF가 있어 지우셔도 영수증은 남습니다.
  • 그림 파일을 지워도 그 그림으로 이미 수금관리에 들어간 줄은 남습니다. 유○○ 님 수금이 두 줄로 들어갔는지는 만들 때 수금 기록을 열어 확인하고, 두 줄이면 보고 드립니다(제가 지우지 않음).

8. 차례와 확인 방법

  1. 서버: 사진 문자 보내기 → 세무사님 휴대폰으로 시험 한 통(110원, 보내기 전 여쭘).
  2. 서버: 목록·판독·한 파일 수금 기록 — 지금 PDF 13개를 판독해 금액·발행처가 밤 작업 결과와 같은지, 같은 파일을 두 번 보내도 수금은 한 번인지.
  3. 화면: 단추·목록·미리 보기 — 가짜 서버 사본으로 PC·폰 폭에서 실제 클릭. PDF 13개 모두 JPG 200KB 안·글자 읽히는지 그림으로 확인.
  4. 넥스 [실행] 카드·이음매 줄.
  5. 커밋·배포는 세무사님 지시 때. 배포 뒤 운영에서: 새 영수증 PDF를 폴더에 저장 → 단추 → 세무사님 휴대폰으로 보내기 → 수금관리에 바로 보이는지.
