메모 한 창 계획서

2026-11-14 · 쓸개 · 넷째 판 · 확정(11-14 세무사님 "권장대로 하자") — 만듦(가지 claude/booking-btn-tidy, 커밋·배포 전) · 가짜 서버 화면 시험·녹음 서버 단독 시험 12 통과

1. 목적

세무사님(11-14): "기능이 너무 많아서 복잡한 것인가? 헷갈린다" → "하나로 합치는 계획서를 만들어라" → (노트북) "걷어내지 말고 폴더만 잘 보여주면 된다" → (이웃 길) "이것도 함께 정비하자" → "권장대로 하자. 필기메모에서 빠져나오는 방법이 없나?" → "전에는 일반메모와 필기메모간에 상호 전환을 하였었잖아" → "메뉴구조를 바꾸다 보니 이렇게 된 것 같은데, <의뢰 메모> 탭을 <메모>로 변경하고, 일반메모와 필기메모를 하나의 창으로 전환하는 방법은 없나?" → "계획서를 고쳐라"
  • 메모는 한 창. 메뉴 「📝 메모」 하나로 들어가, 창 안에서 글·손글씨를 바꿔 쓴다.
  • 상담 내용은 어디서 적든 사건마다 한 곳에 모인다 — 그 사건의 의뢰서 파일. 사건과 상관없는 것만 일반메모로.

바로잡음: 고객관리 「상담기록」은 상담 메모 칸이 아니라 수금(금액·수취증빙)·넥스 문자 발송 기록 표라 이번 정비에서 손대지 않는다.

원인 — 11-01 화면 개편(커밋 3599c415)에서 메뉴의 「📝 일반메모」「✍ 필기메모」 두 줄 중 필기메모를 빼 떠 있는 ✍ 단추로 옮기고, 일반메모 화면 이름을 「의뢰 메모」로 바꿨다. 그 뒤

  • 필기메모에서 나가는 길이 PC 왼쪽 6px 띠·태블릿 ☰뿐이고, 예전의 「일반메모 ↔ 필기메모」 오가기가 없어졌다(PC 크기·태블릿 크기 시험 사본에서 직접 확인).
  • 「의뢰 메모」라는 이름 아래에 고객 메모·일반메모·사건개요·의뢰서 네 갈래가 단추 전환으로 섞였다 — 📋·🗂를 누르면 단추가 숨고 이름이 「📝 텍스트 메모로」로 바뀜, 한쪽을 켠 채 다른 쪽을 누르면 이름이 「사건메모」「의뢰서 작성」으로 바뀜(memo.html 2157·2176줄), 저장 단추 하나가 고객명 유무로 두 갈래, 「저장 위치 (최상위) · + 노트북」 줄이 일반메모일 때만 쓰이는데 늘 떠 있고 고를 폴더도 보이지 않음.
  • 사건 하나의 상담 내용이 「고객명사건.md」·「의뢰서_….md」·사건 줄 「진행메모」·「상담내용_….md」로 흩어지고, 같은 칸을 화면은 「진행메모」, 서버는 「의뢰 메모」, 넥스는 「의뢰개요」로 부른다.

3. 합친 모습

원칙: 사건마다 「상담 내용」 파일 하나 = 그 사건의 「의뢰서_….md」. 어디서 적든 사건에 넣으면 이 파일 맨 앞에 「## 상담기록(날짜 시각 · 어디서)」으로 쌓인다(최신이 앞 — 넥스 첫 응답 앞부분에 걸림). 손글씨 PDF·녹음 원본 같은 원본 파일은 사건 폴더에 그대로 두고 상담기록에 파일 이름을 적어 잇는다.

3-1. 「메모」 한 창 — 글·손글씨 탭

📝 메모
⌨ 글✍ 손글씨사건에 넣기일반메모로 저장
(글 탭일 때) + 새 메모양식 ▾👁 보기메모 찾기 · 꾸밈 도구·찾기/바꾸기·전체화면
(손글씨 탭일 때) ✏ 펜·색·굵기↩ ↪🗑📎 배경▦ 무늬🔍◀ 1/1 ▶
적는 칸(글 탭) / 그림판(손글씨 탭)
  • 메뉴: 「📝 의뢰 메모」 → 「📝 메모」. 메뉴 한 줄로 들어가며 처음엔 글 탭.
  • 탭 바꾸기: 같은 창 안에서 바뀐다(다른 화면으로 넘어가지 않음). 바꾸는 동안 적던 글·그리던 그림은 그대로 남는다.
  • 저장 단추 둘은 두 탭 공통 — 「사건에 넣기」「일반메모로 저장」(3-2·3-3). 글 탭이면 글을, 손글씨 탭이면 그림(PDF)을 넣는다.
  • 떠 있는 ✍ 단추: 어느 화면에서나 「메모」 창을 손글씨 탭으로 연다(㉦). 폰 현장 도구 「필기메모」·넥스의 "필기메모 열어 줘"도 같은 곳.
  • 옛 이름 잇기: 화면 이름표 「memo-text」「memo-hand」를 넥스 화면 목록·사용 설명서·폰 도구 시트가 부르므로, 옛 이름으로 불러도 새 창의 해당 탭이 열리게 잇는다.

3-2. 「사건에 넣기」

  • 창 하나에서 새 사건 등록 또는 기존 사건 고르기.
  • 새 사건: 지금 🗂 의뢰 길 그대로 — 사건 등록 + 「의뢰서_…md」(양식을 불러왔으면 「의뢰서_양식_고객명.md」, 아니면 「의뢰서_상담_고객명.md」) + 글에서 뽑은 이름·날짜·금액·소재지를 사건개요(가설)에 + 기준일. 손글씨면 PDF를 사건 폴더에 넣고 의뢰서 파일엔 「상담기록(시각 · 손글씨) — 파일 이름」.
  • 기존 사건: 그 사건 의뢰서 파일 맨 앞에 상담기록으로 쌓는다(없으면 「의뢰서_상담_고객명.md」를 새로). 뽑은 값은 빈 칸만 가설로 채우고 세무사님이 넣은 값은 바꾸지 않는다(공통원칙 1절).
  • 넣은 뒤엔 지금처럼 「개요로 가기 · 증빙 넣기」 띠.

3-3. 「일반메모로 저장」

  • 사건과 무관한 메모만. 고객명을 묻지 않는다. 글은 .md, 손글씨는 PDF.
  • 저장 창에서 폴더를 펼쳐 놓고 고른다(㉣ 정함): 폴더마다 메모 수·최근 메모 이름 2~3개, 「+ 새 폴더」는 고른 폴더 안에. 이름은 「노트북」 대신 「폴더」.
일반메모로 저장 (그림 — 폴더 이름·개수는 예시, 지금 실제 하위 폴더는 0개)

3-4. 글 탭에서 걷는 것

  • 📋 사건(세목별 칸 입력·초안·「사건개요초안」 폴더 쓰기) — 빈 「사건개요초안」 폴더는 그대로 둠(㉡).
  • 🗂 의뢰 전환 칸 — 양식은 「양식 ▾」로 같은 칸에 불러온다.
  • 저장 창의 고객명 칸, 단추 숨기기·이름 바뀌기, 늘 떠 있던 「저장 위치」 줄. 메모 찾기 목록의 「📁폴더 › 메모」 표시와 #태그는 그대로.

3-5. 작업관리 「진행메모」 칸 (㉤)

  • 이름을 「의뢰 요약」으로, 안내를 "고객이 의뢰한 내용(한두 줄)"로 — 서버·넥스가 이미 이 칸을 의뢰 내용으로 읽고 예약의 「의뢰 내용」도 이 칸으로 들어온다.
  • 처리 계획·처리 결과는 사건의 작업일지(이미 있는 칸)에 — 칸 아래 「작업일지에 적기」 단추. 이미 적힌 글은 그대로.

3-6. 상담 녹음 (㉥)

  • 녹음이 사건에 붙을 때(사건을 골라 녹음 / 보관함에서 사건으로 옮김) 요약을 그 사건 의뢰서 파일 맨 앞에 「상담기록(시각 · 녹음)」으로 쌓고, 녹취 전문·원본 음성 파일 이름을 적어 잇는다. 「상담내용_….md」·원본 음성·작업일지 한 줄은 그대로.
  • 이것만 서버 고침(Consult.js 두 곳) — 서버 배포 필요.

4. 바뀌지 않는 것

  • 사건 등록 입구(의뢰서 글·사건개요를 한 번에 받는 것), 의뢰서 양식 폴더, 넥스·GAS·장부가 읽는 방식(의뢰서는 증빙 아닌 사건파악용).
  • 손글씨 도구와 PDF로 저장하는 방식(글자로 바꾸지 않음).
  • 넥스가 대화에서 "메모로 저장"할 때 여는 저장 창(aichat.html 1864·6101줄) — 3-2·3-3의 같은 갈래로 이어진다.
  • 이미 있는 「고객명사건.md」·「상담내용_….md」·사건개요 값·진행메모 글 — 옮기거나 지우지 않는다(GAS가 지금처럼 가설로 읽음).
  • 고객관리 「상담기록」 표(수금·문자 발송 기록)와 수금 화면.

6. 순서 (확정 뒤)

  1. 「메모」 한 창(memo.html·index.html 메뉴·script.html 화면 이름표) — 글·손글씨 탭, 공통 저장 단추 둘, 옛 이름 잇기, 떠 있는 ✍ 단추.
  2. 글 탭 정리(3-4)·「사건에 넣기」(3-2)·「일반메모로 저장」 폴더 펼침(3-3).
  3. 넥스 저장 창·넥스 화면 이름표 잇기(aichat.html).
  4. 작업관리 「의뢰 요약」·「작업일지에 적기」(workmanage.html).
  5. 상담 녹음 서버 두 곳(Consult.js) + 소통 이음매 점검 줄(Federation.js).
  6. 사용 설명서(manual.html) 메모·작업관리·상담 녹음 절, 폰 현장 도구 시트 이름.
  7. 화면 조립 → 시험 → 커밋·배포는 지시 뒤(서버 고침이 있어 서버 배포·직결 재빌드 포함).

7. 확인 방법

  • 서버를 막은 시험 사본에서 PC·태블릿·폰 크기로 실제 클릭·타이핑·그리기:
    • 메뉴 「메모」 → 글 탭 → 손글씨 탭 → 다시 글 탭: 적던 글·그린 그림이 그대로인지(그림판은 숨겨진 채 크기를 다시 재면 비워질 수 있어 꼭 본다).
    • 떠 있는 ✍ → 손글씨 탭으로 열리는지, 옛 이름(memo-text·memo-hand)으로 불러도 해당 탭이 열리는지.
    • 양식 불러오기 → 사건에 넣기(새 사건: 보내는 값에 의뢰서 글·사건개요·기준일) / 기존 사건(의뢰서 파일 맨 앞에 상담기록) / 손글씨 사건에 넣기(PDF + 한 줄) / 일반메모 저장(고객명 안 묻고 폴더 펼침·새 폴더) / 넥스 저장 창 / 작업관리 「의뢰 요약」·「작업일지에 적기」 / 어떤 순서로 눌러도 단추 이름이 그대로인지.
  • 서버 녹음 두 곳은 단독 시험(가짜 사건·가짜 의뢰서 파일)으로 쌓이는 글 확인.
  • 운영에서 처음 보는 가상사건 하나로 처음부터 끝까지: 메모 등록 → 같은 사건에 글 한 번 더 → 손글씨 넣기 → 녹음 보관함에서 옮기기 → 의뢰서 파일 하나에 최신순 → 넥스가 첫 응답에서 최근 상담을 보는지 → 가상 사건·고객·폴더 지움 [세무사님 몫: 로그인].
