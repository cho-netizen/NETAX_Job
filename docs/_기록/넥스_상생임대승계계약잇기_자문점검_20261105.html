넥스 점검 229 — 「상생임대주택 특례(소득세법 시행령 §155의3) 판정 — 체결 기간·월력 기간·5% 증가율(전환 환산)·양도기한 확인과 「취득으로 승계된 임대차는 직전 계약 아님」·칸 이름 잇기」 자문점검 · 2026-11-05

1세대1주택 판정 도구의 mutualLease 칸(→ 엔진 calculateMutualGrowthLeaseExclusionJS)을 열한 갈래로 돌려 §155의3①~③을 맞췄습니다. 기간·증가율·양도기한은 맞았으나, ①1호 괄호(주택 취득으로 임대인 지위가 승계된 계약은 직전임대차계약이 아님)가 없었고, 넥스에게 보이는 도구 설명엔 칸 이름이 없어(없는 도구 이름만 가리킴) 둘을 고쳤습니다.

1. 사건 (시험용 가정)

  • 1주택 세대가 2022-03-01~2024-02-29 보증금 3억으로 임대한 뒤 2024-02-10 3억 1,500만(5%)으로 2024-03-01~2026-02-28 상생 계약, 2027-06-01 양도. 견주기: 3억 1,600만 / 양도 2028-01-01 / 상생 종료 2027-02-28·양도 2028-02-28·03-01 / 직전 17개월 / 체결 2021-12-19 / 월세 전환(전환율 없음·5%로 4.2억·3.02억) / 전 소유자 계약 승계.

2. 법 (원문을 직접 읽음 — 소득세법 시행령 읽기용 판)

  • §155의3①: 1주택 세대가 1호 직전임대차계약(취득으로 임대인 지위가 승계된 계약 제외) 대비 보증금·임대료 증가율 5% 이내 계약을 2021.12.20~2026.12.31 체결, 2호 직전 임대 1년 6개월 이상, 3호 상생 임대 2년 이상이면, 임대 종료일부터 1년과 2029.12.31 중 빠른 날(2026.12.31 이전 종료면 2027.12.31)까지 양도할 때 §154①·§155⑳1호·§159의4의 거주기간 제한 없음. ②: 보증금↔월세 전환은 민간임대주택법 §44④ 전환율. ③: 월력 계산, 1개월 미만은 1개월. ④: 임차인 사정으로 새 계약이면 합산(시행규칙 요건).

3. 도구가 놓치던 것

  • 기간·증가율·양도기한 맞음: 5% 딱 → 적용, 5% 넘음 → 안 됨, 종료 2026-02-28 → 2027-12-31까지, 종료 2027-02-28 → 2028-02-28까지(03-01은 안 됨), 직전 2022-03-01~2023-07-30(16개월 30일 → 17개월) 미달, 2021-12-19 체결 → 밖, 전환은 전환율 없으면 판단 대기·4.2억(40%) 안 됨·3.02억(0.7%) 적용.
  • 전 소유자가 맺은 임대차를 안고 산 집에서 그 계약을 직전임대차계약으로 넣으면 적용으로 나왔다 — ①1호 괄호로 제외돼야 함.
  • 1세대1주택 판정 도구의 mutualLease 설명이 「calculate_mutual_growth_lease_exclusion과 같은 칸」인데 그 이름의 도구는 넥스 목록에 없어 칸 이름을 알 길이 없었다(도구 부족 — 칸 이름을 설명에 적어 해결).
