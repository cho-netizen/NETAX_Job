넥스 점검 181 — 「부모에게 받은 집을 10년 안에 파는 경우 — 이월과세(§97의2①)와 1세대1주택·고가주택 배제(②2호) 잇기」 자문점검 · 2026-11-05

잇기 점검. 이월과세 계산기(calculate_transfer_tax_with_carryover)가 §97의2②2호 배제를 「전부 비과세」일 때만 걸러, 법 괄호가 명시한 고가주택(12억 초과분만 과세) 1세대1주택은 증여자 취득가액으로 셌습니다. 엔진 두 곳을 고쳤고, 새 넥스 도구·지시문 줄은 없습니다.

1. 사건 (시험용 가정)

  • 「민씨」가 2022-03-01 어머니에게서 아파트(증여 당시 평가 10억, 어머니 취득 2010-05-01 4억)를 받아 증여세 2억을 냈고, 2026-09-01 15억에 팜. 갈래: 다른 집이 있는 2주택 / 1세대1주택(거주 3년) / 11억에 팔아 전부 비과세 / 2025-10-01에 받아 11개월 만에 1세대1주택이라며 팜.

2. 법 (원문을 직접 읽음 — 소득세법 20260101·시행령 20261001 시행판)

  • §97의2①: 양도일부터 10년 안에 배우자·직계존비속에게서 받은 부동산 등은 취득가액을 증여자의 취득가액으로, 증여자 필요경비 포함, 낸 증여세 상당액 필요경비 산입. ③ 연수는 등기부 소유기간.
  • §97의2②: ①을 적용하지 않는 경우 — 1호 사업인정고시 2년 전 증여 뒤 수용, 2호 ①을 적용할 경우 §89①3호 각 목의 주택[비과세대상에서 제외되는 고가주택(딸린 토지 포함)을 포함한다]의 양도에 해당하게 되는 경우, 3호 ①을 적용한 결정세액이 미적용 결정세액보다 적은 경우.
  • 시행령 §163⑨: 증여(부담부증여 채무액 부분 포함)받은 자산의 취득가액은 증여일 현재 상증법 §60~§66 평가액. §163의2②: 증여세 상당액 = 산출세액 × 해당 자산 과세가액 ÷ 전체 과세가액, 한도 = 양도가액 − (증여자 취득가액 + 필요경비).

3. 도구가 놓치던 것

  • 이월과세 판정(resolveCarryoverAcquisitionBasis_)이 ②2호를 「이월과세 적용 결과가 비과세여부=true」일 때만 걸렀음. 고가주택 1세대1주택은 12억 초과분이 과세라 비과세여부가 없고, 그래서 배제되지 않은 채 증여자 취득가액 4억·보유 16년으로 셌음(산출 14,376,000). 법 괄호는 고가주택을 명시해 배제 대상에 넣음 — 맞는 셈은 수증자 취득가액 10억·보유 4년(산출 10,920,000).
  • 같은 틈 때문에 증여 11개월 뒤 1세대1주택이라며 팔면, 이월과세(증여자 보유 16년)로 2년 보유가 되는 것처럼 비과세 쪽으로 흘렀음 — ②2호가 막으려던 바로 그 경우.
  • 2주택·전부 비과세·비교과세(②3호) 갈래는 맞게 돌고 있었음. 부담부증여로 받은 자산의 유상 부분에 이월과세를 어떻게 적용하는지는 법령 문언이 없음(검토대상 1).

4. 고친 것 (이 컴퓨터만, 서버 올리기 전)

  • 엔진 양도세 결과에 표지 「고가주택_1세대1주택」(§89①3호 주택으로 12억 초과분만 과세 — core.isOneHouse 또는 재건축 상세의 고가 비율)을 더하고, 이월과세 판정의 ②2호 조건을 「비과세여부 또는 고가주택_1세대1주택」으로 넓힘. 배제 사유 글에 「(고가주택 — 괄호)」를 붙임.
  • 조립본 app/index.html 다시 만듦(tools/build-app.js). 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).

2②2호 「①을 적용할 경우 … 해당하게 되는 경우」를 「이월과세로 셌을 때 1세대1주택(고가 포함)이면 배제」로 읽음 — 수증자 스스로 2년을 채운 경우도 배제되어 수증자 취득가액(증여 평가액)으로 셈그렇게 셈높음
