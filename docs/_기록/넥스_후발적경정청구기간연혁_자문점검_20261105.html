연혁 점검. 「후발적경정청구」 묶음이 모든 사유에 「안 날부터 3개월」을 적용했습니다. 3개월은 2023-01-01 시행 개정이고, 부칙은 시행 전에 종전 2개월이 이미 지난 분을 종전 규정으로 둡니다. 옛 사유를 되짚는 자리에 연혁을 넣었습니다. 새 넥스 도구·지시문 줄은 없습니다.

1. 사건 (시험용 가정)

  • 「곽씨」 상속세(신고기한 2018-09-30) — 상속재산 소송 확정판결을 안 날이 2022-09-01 / 2022-11-01 / 2022-12-01 / 2026-06-01인 네 갈래. 각각 후발적 경정청구 마감이 언제인가.

2. 법 (원문을 직접 읽음 — 국세기본법 정비본)

  • §45의2②: 후발적 사유가 발생한 것을 안 날부터 3개월 이내에 경정청구(개정 2015.12.15, 2022.12.31). 2022.12.31 개정 부칙 §2: ① §45의2②의 개정규정은 시행 이후 결정·경정을 청구하는 분부터 적용 ② 시행 전에 종전 청구기간(2개월)이 지난 분은 종전 규정.

3. 도구가 놓치던 것

  • 안 날 2022-09-01(종전 2개월 마감 2022-11-01, 시행 전 경과)에 3개월(2022-12-01)을 적용 — 부칙 §2②로 이미 2022-11-01에 마감된 청구를 「아직 됨」으로 냈음.

4. 고친 것 (이 컴퓨터만, 서버 올리기 전)

  • JudgeMore.js 「후발적경정청구」 묶음: 안 날 + 2개월이 2023-01-01 전이면 종전 2개월(마감·근거에 부칙 §2② 표시), 아니면 3개월. 공휴일 옮김은 그대로.
  • 엔진·Code.js는 손대지 않음. 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).
