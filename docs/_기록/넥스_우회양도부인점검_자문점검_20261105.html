넥스 점검 249 — 「증여 뒤 우회양도 부인(소득세법 §101②③) 계산기 점검 — 수증자 증여세+양도세 vs 증여자 직접 양도세, 10년(2023 전 5년) 경계, 실질 귀속·이월과세 대상 제외」 자문점검 · 2026-11-05

계산기(calculate_donor_direct_transfer_deemed)를 일곱 갈래로 돌려 §101②③·법률 제19196호 부칙(2023.1.1 전 증여 5년)을 맞췄습니다. 모두 조문대로였고 코드 변경은 없습니다.

1. 사건 (시험용 가정)

  • 형이 2023-03-01 동생에게 땅을 증여(증여세 4천만), 동생이 2026-05-01 양도(양도세 1천만). 형이 직접 팔았으면 양도세 1.2억. 견주기: 수증자 세액 1.3억 / 2022년 증여 뒤 7년 / 2023년 증여 뒤 7년·꼭 10년·다음 날 / 배우자(이월과세) / 양도대금이 동생에게 실질 귀속.

2. 법 (원문을 직접 읽음 — 소득세법 읽기용 판)

  • §101②: 특수관계인(§97의2① 이월과세 적용 배우자·직계존비속 제외)에게 증여한 뒤 수증자가 증여일부터 10년 안에 양도했고, 1호(수증자 증여세 + 양도세) < 2호(증여자 직접 양도 양도세)면 증여자가 직접 양도한 것으로 봄 — 단서: 양도소득이 수증자에게 실질 귀속되면 제외. ③: 그때 당초 증여엔 증여세를 안 매김. 2023.1.1 전 증여는 5년(법률 제19196호 부칙 §18).

3. 도구가 놓치던 것

  • 없음 — 5천만 < 1.2억 → 부인(증여자 양도세 1.2억) / 1.3억 ≥ 1.2억 → 그대로 / 2022년 증여 7년 뒤 → 5년 밖 / 2023년 증여 7년·꼭 10년 안·다음 날 밖 / 이월과세 대상·실질 귀속 → 제외.

4. 고친 것

  • 없음(점검서만). 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).
