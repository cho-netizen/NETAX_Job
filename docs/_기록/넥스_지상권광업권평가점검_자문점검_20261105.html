계산기(calculate_ground_right_value·calculate_mining_right_value)를 세 갈래로 돌려 조문과 맞췄습니다. 모두 조문대로였고 코드 변경은 없습니다. 236에서 비워 둔 영업권 환산 조문(시행규칙 §16② — 지상권과 같은 산식)도 이번에 찾아 236 점검서를 고쳤습니다.

1. 사건 (시험용 가정)

  • 아버지가 남긴 지상권(토지가액 10억, 잔존 15년)과 광업권(전 3년 평균소득 2억, 채굴 가능 10년; 15억에 매입해 2억 상각).

2. 법 (원문을 직접 읽음 — 상증령 20261001 시행판·시행규칙)

  • 시행령 §51①: 지상권 = 토지가액 × 시행규칙 율(§16① 연 2%)을 잔존연수(민법 §280·§281 준용)로 환산(§16② 각 연도 수입 ÷ 1.1ⁿ 합계). 시행령 §59⑥: 광업권·채석권 = 평가기준일 전 3년 평균소득(실적 없으면 예상 순소득)을 채굴 가능 연수로 환산(§19⑤ ÷ 1.1ⁿ 합계), 조업 가치 없으면 설비로만. §64: 취득가액 − 감가상각과 큰 값. 시행규칙 §16②는 영 §59② 영업권 환산에도 같이 쓰임.

3. 도구가 놓치던 것

  • 없음 — 지상권 10억 × 2% = 2천만 × 7.606(15년) = 1억 5,212만 / 광업권 2억 × 6.1446(10년) = 12억 2,891만 / 매입 15억 − 2억 = 13억이 크면 13억.

4. 고친 것

  • 없음(점검서만; 236 점검서 검토대상 1 문구 고침). 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).
