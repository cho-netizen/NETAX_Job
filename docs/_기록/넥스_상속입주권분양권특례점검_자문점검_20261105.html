넥스 점검 245 — 「상속받은 조합원입주권·분양권과 일반주택의 1세대1주택 특례(소득세법 시행령 §156의2⑥⑦·§156의3④⑤) 계산기 점검 — 피상속인 주택 미보유 요건·입주권+분양권만 보유 선택·공동상속 최대지분」 자문점검 · 2026-11-05

계산기(calculate_inherited_union_right_exclusion·calculate_inherited_presale_right_exclusion)를 여섯 갈래로 돌려 §156의2⑥⑦⑮·§156의3④⑤를 맞췄습니다. 모두 조문대로였고 코드 변경은 없습니다.

1. 사건 (시험용 가정)

  • 1주택 세대가 아버지에게서 재개발 조합원입주권(또는 분양권)을 상속받은 뒤 일반주택을 양도. 견주기: 아버지가 사망 당시 주택(또는 분양권)도 보유 / 입주권+분양권만 보유 / 형제와 공동상속(소수지분).

2. 법 (원문을 직접 읽음 — 소득세법 시행령 읽기용 판)

  • §156의2⑥: 상속받은 조합원입주권(피상속인이 상속개시 당시 주택·분양권을 소유하지 않은 경우만; 2개 이상이면 순위에 따른 1개; 공동상속입주권은 ⑦3호 최대지분자(→거주자→최연장자) 외는 소유로 안 봄)과 일반주택을 각 1개 둔 1세대가 일반주택을 양도하면 1주택으로. ⑮: 피상속인이 입주권과 분양권만 두었으면 상속인이 하나를 골라 적용. §156의3④⑤: 분양권도 같은 구조(순위 2단계, 공동상속은 ⑤5호 최대지분→최연장자).

3. 도구가 놓치던 것

  • 없음 — 기본 적용 / 피상속인 주택·분양권 보유면 안 됨 / 입주권+분양권만이면 선택 가능 / 공동상속 소수지분이면 소유로 안 봄(적용) — 분양권 쪽도 같음.

4. 고친 것

6. 검토대상

#무엇지금 도구가 하는 것확신
1피상속인이 2개 이상 입주권(분양권)을 두었을 때의 순위(소유기간 합산 최장→거주 최장→선택)는 사람이 정해 「그 1개」로 넣음전제높음
2상속받은 입주권이 나중에 주택이 된 뒤 양도할 때(§155② 상속주택 특례와의 관계)는 이 계산기 밖—중간
3⑥ 괄호 「상속개시 당시 주택·분양권 미소유」 판정에 피상속인의 공동소유 소수지분 주택이 드는지는 해석례칸중간
4일반주택을 「상속 외 원인으로 취득」(⑤)한 것인지·상속개시 전 취득 요건(2014.2.21 이후 상속분)은 1세대1주택 묶음이묶음중간
5공동상속 최대지분자 뒤 순위(거주자·최연장자)는 사람이칸높음
