1. 목적

지금은 솔라피가 문자를 받아 간 것까지만 넥스가 압니다(보냄 표시·수금·상담기록). 고객 휴대폰에 실제로 도착했는지를 넥스 화면에서 보이게 하고, 도착하지 못했으면 세무사님께 알립니다.

2. 솔라피가 알려 주는 것 (공식 문서에서 확인)

무엇내용출처
도착 결과 조회메시지 번호로 「메시지 목록 조회」를 부르면 상태(대기·전송 중·처리 완료)와 결과 코드·까닭 글을 돌려줌solapi.com/developers/api/msg-getList

대표 실패3043 단말기 전원 꺼짐 · 3042 음영지역 · 3061 수신거부 · 3054/3055 스팸 · 3032 미가입자 · 3010 번호 형식 오류 · 3041 통화 중 · 3040 전송시간 초과같은 문서

결과가 확정되기까지 걸리는 시간은 문서에 적혀 있지 않습니다 [확인 필요 — 만든 뒤 실제 문자로 잼].

3. 이렇게 만듭니다

보내기→솔라피 답에서 메시지 번호 받아 영수증 파일에 적음→「확인 중」→1분 틱이 결과 조회→도착 또는 실패: 까닭
  1. 메시지 번호 남기기 — 보낼 때 솔라피 답에 든 메시지 번호를 영수증 파일 표시(보낸 시각 옆)에 함께 적습니다. 지금은 이 답을 버리고 있습니다.
  2. 결과 묻기 — 이미 1분마다 도는 서버 틱이, 「확인 중」인 영수증 문자가 있을 때만 솔라피에 결과를 묻습니다(없으면 아무것도 안 함). 결과가 확정되면(처리 완료) 파일에 「도착 ○○:○○」 또는 「실패 — 까닭」을 적고 더 묻지 않습니다. 하루가 지나도 확정이 안 되면 「결과 모름」으로 닫습니다.
  3. 보이는 곳
    • 「📱 영수증 문자」 창 목록: 지금의 보냄 11-26 자리에 확인 중 → 도착 11-26 / 실패(마우스를 올리면 까닭·시각).
    • 보낸 직후 창: 창을 닫지 않고 있으면 몇 초 뒤 같은 줄에 결과가 바뀌어 보입니다.
    • 고객관리 상담기록: 보낼 때 적은 「문자 발송」 줄 아래에 결과 한 줄(「도착」 또는 「도착 실패 — 단말기 전원 꺼짐」).
  4. 실패하면 알림 — 대시보드 알림과 아침 알림 묶음에 「영수증 문자 도착 실패: ○○○ — 까닭」 한 줄. 다시 보내기는 그 영수증을 창에서 다시 고르면 됩니다(지금처럼 「이미 한 번 보낸 영수증」 알림 뒤 보낼 수 있음).
  5. 수금은 그대로 — 수금 기록은 돈을 받은 사실이라 문자 도착과 상관없이 그대로 둡니다.
  6. 시험 보내기도 결과를 받아 보낸 창에 「도착」을 보입니다(파일·기록에는 안 남김) — 만든 뒤 이것으로 도착 확인을 시험합니다.

4. 정할 것

번호정할 것권장까닭
㉠결과를 받는 방법 — 넥스가 1분마다 묻기 / 솔라피가 알려 주기(웹훅)1분마다 묻기웹훅은 로그인 없이 바깥에서 들어오는 입구를 하나 더 열어야 하고, 우리 서버는 깨어나는 데 7초 넘게 걸려 솔라피의 5초 제한에 자주 걸립니다. 묻기는 「확인 중」이 있을 때만 돌아 비용·부담이 거의 없습니다.
㉡범위 — 영수증 사진 문자만 / 넥스가 보내는 모든 문자(예약 알림 등)영수증 사진 문자만말씀하신 것은 영수증 문자입니다. 다른 문자는 보내는 곳이 여럿이라 따로 정하실 일입니다.
㉢실패 알림 자리 — 대시보드 알림+아침 묶음 / 세무사님 휴대폰 문자대시보드 알림+아침 묶음휴대폰 문자는 건마다 돈이 들고, 영수증 문자는 세무사님이 창에서 직접 보내시므로 화면 알림으로 충분합니다.

5. 순서와 확인 방법

  1. 서버: 메시지 번호 저장·결과 묻기·파일 표시·상담기록·실패 알림(가짜 솔라피로 성공·실패·하루 넘김 시험).
  2. 화면: 목록 표시 세 가지·보낸 뒤 결과 바뀜(서버 막은 시험 사본 PC·폰).
  3. 세무사님 「커푸배」 뒤: 운영에서 세무사님 휴대폰으로 시험 한 통 → 창에 「도착」이 뜨는지, 걸린 시간을 재어 이 계획서 2절 [확인 필요]를 채움.

6. 만든 것 (11-26, 커밋 전)

  • 서버 gs-backend/ReceiptSmsTrack.js(새 파일 — 올릴 때 clasp push 필요): 메시지 번호 읽기·따라가는 목록·결과 묻기·확정·실패 알림·창 결과 묻기. ReceiptSms.js: 보낼 때 번호 남기기·목록에 결과. Code.js 1분 틱에 한 줄. Federation.js 이음매 점검 한 줄(1분 틱이 10분 넘게 안 물으면 ⚠).
  • 화면 receiptsms.html: 목록 표시(확인 중·도착·도착 실패·결과 모름, 예전 것은 보냄) · 보낸 뒤 창에 「도착」 칸(15초마다 5분까지, 닫으면 멈춤). dashboard.html: 「문자 실패」 알림 그림 📱.

  • 남은 것: 운영에서 실제 한 통으로 결과까지 걸린 시간·솔라피 답 모양 확인(2절 [확인 필요]).
