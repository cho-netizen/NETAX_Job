넥스 점검 204 — 「필요경비 가르기(소득세법 §97·시행령 §163) — 「중개보수」가 수선으로 잡히던 틈」 자문점검 · 2026-11-05

잇기 점검. 「필요경비」 묶음을 흔한 항목으로 돌렸습니다. 취득세·발코니 확장·도배·대출이자·증빙 없는 새시는 법대로였으나, 「중개보수」(양도 소개비)가 이름의 「보수」 글자 때문에 수선(수익적지출)으로 잡혀 「필요경비 아님」이 됐고, 「복비」는 「갈림」이었습니다. 글자 규칙을 고쳤습니다. 새 넥스 도구·지시문 줄은 없습니다.

1. 사건 (시험용 가정)

  • 「주씨」 아파트 양도(취득 2015-03-01, 양도 2026-09-01) 지출: 취득세 1,200만·발코니 확장 1,500만(세금계산서)·도배장판 300만·중개보수 800만(현금영수증)·신고 수수료 50만·대출이자 2,000만·새시 교체 900만(증빙 없음). 고친 뒤 「복비」·「취득 중개보수」·「보수 공사(외벽 방수)」도 함께.

2. 법 (원문을 직접 읽음 — 소득세법 시행령 20261001 시행판)

  • §163①1호·§97①1호: 취득 부대비용(취득세·등기비·취득 중개보수)은 취득가액. §163③: 자본적지출(§67② 준용 — 용도변경·개량·이용편의)·증빙(§160의2② 또는 금융거래 증명) 있을 때만. §163⑤1호: 양도비 — 신고서·계약서 작성비·공증·인지·소개비·명도비용 등, 증빙 요건 같음. 대출이자는 취득원가 아님(§163①3호 단서).

3. 도구가 놓치던 것

  • 「중개보수」 → 「보수」 글자가 수선 규칙(/도배|장판|…|보수|…/)에 먼저 걸려 「원상회복·유지 수선 — 필요경비 아님」. 「부동산 중개수수료」로 적으면 양도비로 맞게 감 — 같은 지출이 이름에 따라 800만원이 들쭉날쭉. 「복비」는 양도비 규칙 글자에 없어 「갈림」.
  • 나머지: 취득세 → 취득가액, 발코니 확장 → 자본적지출(확인 필요 꼬리), 도배장판 → 아님, 대출이자 → 아님(§163①3호), 새시(증빙 없음) → 인정 안 됨 + 증빙 확보 할 일, 신고 수수료 → 갈림(검토대상 1).

4. 고친 것 (이 컴퓨터만, 서버 올리기 전)

  • JudgeMore.js 「필요경비」 묶음: 수선 규칙에 「중개·소개·수수료·복비」 글자가 있으면 걸리지 않게 예외, 양도비 규칙에 「복비」 추가 → 「중개보수」·「복비」는 양도비(§163⑤1호), 「취득 중개보수」(언제=취득)는 취득가액. 「보수 공사(외벽 방수)」는 그대로 수선.
  • 엔진·Code.js는 손대지 않음. 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).
