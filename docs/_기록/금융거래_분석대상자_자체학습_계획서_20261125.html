2026-11-25 0시 · 가지 claude/fin-10y-review · 세무사님 "충분한 시간과 자원을 가지고 내일 아침 8시까지 나에게 확인이나 허락받지 말고 완전 자동모드로 일하라" — 이 계획서는 확인을 받지 않고 그대로 만든다(기록용).

2. 주요 거래대상자를 어디서 찾나

  • 사건 폴더 계약서(임대차·매매·분양·전세 — 파일 이름으로 고름)의 글자(이미 읽어 둔 글자 기억만, 새 글자인식은 1분 틱에서 하지 않음)에서 「임대인·임차인·매도인·매수인」 이름·계약일·보증금·대금 → 피상속인이 아닌 쪽을 대상자로(갈래 짐작: 세입자·임대인·매수인·매도인), 계약일은 「관련 거래·계약」 칸으로 → C4(계약일 전후 인출)·보증금 짝 맞추기.
  • 큰돈(1천만원 이상)이 오간 상대 — 후보로.
  • 모두 짐작이고 갈래 확정은 세무사님(✎).

4. 지키는 것

  • 판단(증여·대여·소명·특수관계·상속인)은 세무사님. 짐작에는 늘 「짐작」·「배움」 표시. 성씨만 같은 것은 맞춤 아님.
  • 고객 원본 파일·세무사님 엑셀은 읽기만. 보고서는 GAS 표시 사이만 고침.
  • 고객 글을 바깥 AI로 보내지 않음(모두 GAS).
  • 보고서 저절로 만들기는 「사건 기준」 탭에서 끌 수 있음(11-14 "내가 검토서를 만들라고 한 사건만"과 이번 "보고서작성까지 모두 연결" — 이번 말씀을 따르되 사건마다 끌 수 있게).

5. 확인 방법

이 컴퓨터에서 다섯 사건 진행 기록 사본으로 끝까지(가짜 시트·가짜 드라이브), 숫자 검산(증감분석 끝 잔액 = 전체 잔액, 대상자 합 = 거래 합), 다시 돌려도 같음, 세무사님 ✎ 옮김 → 커밋·금융 서버 배포 → 운영 시트·보고서 파일을 드라이브에서 직접 열어 확인.
