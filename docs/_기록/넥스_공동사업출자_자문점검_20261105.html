넥스 점검 167 — 「공동사업(동업)에 부동산 현물출자·탈퇴 — 양도인가, 얼마가, 언제」 자문점검 · 2026-11-05

1. 사건 (시험용 가정)

  • 「추씨」가 2010년 3억에 산 땅(시가 8억)을 2026년 3월 남과 50:50 임대 동업(조합)에 출자하고 3월 15일 합유 등기. 추씨는 「내 땅을 내가 하는 사업에 넣은 것」이라 양도가 아니라고 생각하고, 혹시 양도라도 남의 지분 50%만이라고 봄.
    • 다른 경우: 아들과 동업하며 출자가액 5억(시가 8억) · 2028년 탈퇴하며 정산금 6억(조합 땅 시가 14억·지분 50%) · 분양 목적 조합·출자공동사업자.

2. 법 (원문을 직접 읽음 — 소득세법 20260701·시행령 20261001 시행판)

  • 소득세법 §88 1호: 「양도」 = 등기·등록과 관계없이 매도, 교환, 법인에 대한 현물출자 등을 통하여 자산을 유상으로 사실상 이전. 공동사업(민법상 조합)에 대한 현물출자는 「등」에 들어가고, 출자한 부동산은 조합원 전원의 합유가 되므로 전체가 양도 — 판례의 결론이나 판례 원문은 시스템에 없음 [확인 필요].
  • §96①: 양도가액 = 실지거래가액(출자 때 평가한 가액). §101①·시행령 §167③④: 특수관계인에게 시가보다 낮게(3억 또는 5% 이상) → 시가로. 시행령 §162①1·2호: 대금 청산 전 등기면 등기접수일.
  • §43①②③: 공동사업장을 1거주자로 보아 소득을 계산하고 손익분배비율로 분배, 특수관계인 거짓 비율이면 주된 공동사업자 소득. §17①8호: 출자공동사업자 분배금은 배당소득. 탈퇴 정산금은 조합 재산 지분의 유상 이전 → 양도 [확인 필요 — 판례].

3. 도구가 놓치던 것

  • 공동사업 출자를 가르는 자리가 없었습니다(「양도여부」 묶음은 공유물분할·교환·양도담보·신탁·환지만). 넥스가 ① 출자를 양도 아님으로 보거나(무신고) ② 자기 지분을 빼고 남의 지분만 양도로 보거나(8억 → 4억) ③ 양도가액을 장부가로 적거나 ④ 가족 조합원과의 저가 출자(부당행위·증여)와 ⑤ 탈퇴 정산금(지분 양도)을 놓칠 수 있었습니다.

4. 고친 것 (이 컴퓨터만, 서버 올리기 전)

  • 판정 묶음 「공동사업출자」를 새로 만들었습니다(JudgeMore.js). 별칭 「동업출자」·「조합출자」·「공동사업탈퇴」·「현물출자양도」. 하는 일: 출자 = 전체 양도 → 양도가액(출자 평가액, 특수관계 저가면 시가) → 양도시기(등기접수일) → 조합 소득 성격 알림(임대 분배·분양 사업소득·출자공동사업자 배당) → 조합 지분 취득가액 → 탈퇴 정산 지분 양도(지분 시가보다 적으면 저가 알림) → 경우(전체 양도 / 양도 아님 / 자기 지분 빼고 / 장부가 / 탈퇴).
  • 넥스 judge 도구의 묶음 이름·칸 설명(Code.js — 새 도구·지시문 줄 없음, 검문 ✓), 소통 이음매 줄(Federation.js).
  • 일반 규칙 한 줄: 「소유 형태가 바뀌는 모든 길(현물출자·합유·신탁·교환)은 ‘누구 것이었다가 누구 것이 되나’로 양도 여부를 가르고, 내 몫이 남아 보여도 법률상 전부 넘어갔으면 전부 양도」 — 법인 현물출자(§32 이월과세)와 같은 틀.
