넥스 점검 190 — 「조합원입주권 자체를 파는 경우의 비과세(법 §89①4호) — 종합판정 잇기」 자문점검 · 2026-11-05

잇기 점검. 종합판정(judge_tax_relief)은 양도하는 물건이 조합원입주권이어도 주택처럼 §89①3호 셈표(양도일 기준 보유·거주 2년, 다른 주택이 있으면 「맞는 특례 없음」)로 가르고 있었습니다. 입주권 자체 양도는 §89①4호(인가일 현재 기존주택 요건 + 가목 다른 주택·분양권 없음 / 나목 1주택 취득 3년 안 양도 + 12억 단서)라 별도 갈래를 넣었습니다. 새 넥스 도구·지시문 줄은 없습니다.

1. 사건 (시험용 가정)

  • 「석씨」가 2012년 취득한 집이 2022-05-01 관리처분계획 인가로 조합원입주권이 됨. 2026-09-01 입주권을 9억에 양도. 갈래: 다른 물건 없음 / 2024-06-01 취득한 새집 있음(나목 3년 안) / 2022-06-01 취득 새집(3년 넘김) / 새집 + 2021년 분양권 / 2020년 분양권만 / 다른 입주권 / 인가일 현재 조정지역·거주 12개월 / 15억·3년 넘김·부득이 사유 / 인가일 모름.

2. 법 (원문을 직접 읽음 — 소득세법 20260101 시행판)

  • §89①4호: 조합원입주권을 1개 보유한 1세대[관리처분계획 인가일·사업시행계획인가일(그 전 철거면 철거일) 현재 3호가목 요건을 갖춘 기존주택을 소유하는 세대]가 가. 양도일 현재 다른 주택 또는 분양권을 보유하지 않거나 나. 1조합원입주권 외 1주택만 보유(분양권 없음)하고 그 주택 취득일부터 3년 안(부득이한 사유 포함)에 양도하면 비과세. 단서: 양도 당시 실지거래가액 12억 초과면 과세.
  • 법률 제17477호 부칙 §4(분양권 2021-01-01 이후 취득분부터)는 §89②·§104⑦에 명시 — 4호의 「분양권」 문구도 같은 개정이라 같은 적용례로 봄 [확인 필요].

3. 도구가 놓치던 것

  • 입주권 자체 양도를 §89①3호로 가름 — ① 「인가일 현재」가 아니라 양도일 기준으로 보유·거주를 봤고(인가 뒤 거주는 불가능한데 거주 2년을 요구) ② 다른 주택이 1채 있으면 나목(취득 3년 안) 특례 없이 「맞는 특례 없음 — 안 됨」 ③ 고가 기준 조문이 3호 괄호로 적힘.
