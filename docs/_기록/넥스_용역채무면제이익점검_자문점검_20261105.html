넥스 점검 211 — 「용역·재산 사용 이익(상증법 §42·시행령 §32)과 채무면제 이익(§36) 계산기 점검 — 1천만·30% 문턱」 자문점검 · 2026-11-05

두 계산기(calculate_property_use_service_gift_tax·calculate_debt_forgiveness_gift_tax)를 일곱 갈래로 돌려 §42① 단서의 기준금액(무상 1천만·저가·고가 시가 30%)과 §36(기준금액 없음, 보상액 차감)을 맞췄습니다. 모두 조문대로였고 코드 변경은 없습니다.

1. 사건 (시험용 가정)

  • 아버지 회사가 아들에게 연 시가 3천만 상당 용역을 무상(또는 800만 시가) / 2,500만·1,500만 대가로 제공. 아버지가 아들 빚 5천만·800만 면제, 5천만 빚을 3천만 보상받고 인수.

2. 법 (원문을 직접 읽음 — 상증법 20260102·시행령 20261001 시행판)

  • §42①: 재산(부동산·금전 제외) 사용·용역 제공의 무상·저가·고가 이익(시가와 대가의 차액)을 증여재산가액으로, 단 기준금액 미만 제외 — 시행령 §32②: 무상은 1천만, 저가·고가는 시가의 30%. ②: 기간 없으면 1년, 1년 넘으면 매년 새로. §36①: 채무 면제·인수·변제 이익(보상액 차감) — 문턱 없음, 증여일은 면제 의사표시일·인수계약일(시행령 §26의2).

3. 도구가 놓치던 것

  • 없음 — 무상 3천만 과세·800만 제외 / 저가 차액 500만(< 900만) 제외·차액 1,500만 과세 / 채무면제 5천만·800만 모두 과세(문턱 없음), 인수 보상 차감 2천만.

4. 고친 것

  • 없음(점검서만). 넥스 지시문·도구 수 그대로(검문 ✓ 78개·25,224자).
