현금영수증 사진 문자 보내기 — 계획서

2026-11-25 · 확정 전 · 가지 claude/receipt-mms(아직 코드 안 고침)
세무사님 말씀(원문)
"단순 상담고객에게 현금영수증을 보내주어야 하는데, 문자메시지로 보내주어야 한다. 현재 대부분의 경우 카카오채널로 pdf파일로 다운받은 현금영수증을 보내주고 있는데, 단순상담고객은 카카오채널로 보내줄 수가 없어서 일일이 화면을 캡쳐하여 그림파일로 저장한다음 카카오로 나에게 보내기 한 다음 스마트폰에서 다운로드한 다음에 문자메시지로 보내주고 있다. 이 것을 넥스시스템에서 직접 보내주는 것을 구현해 달라"
"참고로 단순고객의 현금영수증은 고객사건폴더아래 <1 상담사건>폴더에 현금영수증 pdf파일을 저장하고 있다"

1. 목적

「1 상담사건」 폴더의 현금영수증 PDF를 넥스 화면에서 사진 문자(MMS)로 고객 휴대폰에 바로 보낸다. 지금 손으로 하시는 캡쳐 → 나에게 보내기 → 폰에서 받기 → 문자 보내기 네 단계를 단추 한 번(미리 보기 확인 뒤 보내기)으로 줄인다.

2. 지금 있는 것 (코드·폴더에서 직접 확인)

무엇지금 상태
문자 보내기솔라피(SOLAPI)로 글 문자만 보냄(서버 문자 보내는 함수 하나를 예약 알림·고객 문자·고객창구 안내가 같이 씀). 고객관리 「문자 보내기」 창이 있음.
9월에 같은 일2026-09-18 "현금영수증 파일을 보내줘야 하는데 보낼 방법이 없다"는 말씀에 "솔라피 문자는 글만 된다"고 잘못 보고 공유 링크를 붙여 넣는 방식으로 대신했음(코드 주석에 그대로 남아 있음). 실제로는 솔라피가 사진 문자를 지원함 — 아래 3절.
「1 상담사건」 폴더J: 고객사건\1 상담사건에 영수증 PDF 16개(「전○○_현금영수증.pdf」처럼 고객명_현금영수증 이름, 각 52~56KB). 오늘 16:24에 손으로 만드신 「전○○_현금영수증.png」(50KB)·11-17 「유○○_현금영수증.png」가 함께 있음.
수금 인식밤 2시·대시보드 「확인」 때 이 폴더 영수증을 읽어 고객명으로 수금에 기록(「사건 미연결」 표시). 파일 이름에서 고객명을 읽음.
PDF를 그림으로넥스 화면(app)에 이미 PDF 그리기 도구(pdf.js)가 들어 있음 — 첫 쪽을 그림으로 바꿀 수 있음.

3. 솔라피 사진 문자 규격 (공식 SDK 소스에서 확인)

  • 사진 올리기: POST storage/v1/files, 본문 file(그림을 base64로)·type: "MMS"·name → 답의 fileId.
  • 보내기: 지금 쓰는 messages/v4/send에 imageId(위 fileId)·subject(제목)·text를 넣으면 사진 문자로 나감.
  • 사진 크기 200KB까지. 형식은 SDK 예제가 JPG뿐이라 JPG로 만든다(PNG 허용 여부는 확인 못 함 — JPG면 걱정 없음).
  • 요금: 사진 문자 110원/통(글 장문 45원, 단문 18원, 부가세 별도).
  • 열쇠·발신번호는 지금 것을 그대로 씀(새 계약·새 열쇠 없음).

4. 쓰시는 차례 (화면)

수금 화면 그 줄 · 또는 고객관리 그 고객→📱 영수증 문자→미리 보기 창(영수증 그림·받는 번호·글)→보내기→「보냈습니다」 + 상담 기록 한 줄
  1. 단추 자리 — ① 수금 화면에서 현금영수증으로 들어온 줄(특히 「사건 미연결」 상담 고객 줄)에 「📱 영수증 문자」 ② 고객관리 「문자 보내기」 창에 「영수증 붙이기」(그 고객 이름의 영수증 파일을 골라 붙임).
  2. 미리 보기 창 — 영수증 첫 쪽을 그림으로 바꿔 크게 보여 드림(빈 여백은 잘라 냄) · 받는 번호(고객관리 전화번호, 없으면 예약 기록의 번호, 그래도 없으면 입력칸) · 글 기본값 「이음세무컨설팅입니다. 요청하신 현금영수증을 보내 드립니다.」(고칠 수 있음) · 요금 「사진 문자 110원」 · [보내기] [닫기].
  3. 보낸 뒤 — 그 고객 상담 기록에 「문자 발송(현금영수증 사진) — 파일명」 한 줄. 실패하면 까닭(잔액·번호 틀림 등)을 그대로 보여 드리고 기록하지 않음.

5. 만드는 것

자리할 일
서버(문자)사진 올리기 + 사진 문자 보내기 함수 하나. 지금 글 문자 함수는 그대로 두고 옆에 더함(예약 알림 등 다른 문자에 영향 없음). 실패 기록은 지금 문자 실패 기록에 같이.
서버(영수증 찾기)고객명으로 「1 상담사건」(하위 폴더 포함)과 그 고객 사건 폴더의 「현금영수증」 PDF 목록 — 최근 것 먼저.
화면단추 두 자리·미리 보기 창·PDF → JPG(200KB 넘으면 화질·크기를 줄여 다시).
넥스지금 넥스가 쓰는 「고객 문자」 [실행] 카드에 영수증 파일을 붙일 수 있게(세무사님이 [실행]을 누르셔야 나감 — 지금 방식 그대로).
점검소통 이음매 점검 목록에 이 길 한 줄 · 변경 점검(바깥 호출이 솔라피 하나 늘어남 — 고객 서류 그림이 솔라피로 나가는 것은 세무사님이 단추를 누를 때만).

6. 정하실 것 (권장안 먼저)

물음권장안
㉠단추 자리수금 화면 줄 + 고객관리 문자 창 둘 다(4절).
㉡만든 JPG를 폴더에 남길지남기지 않음. 같은 폴더에 그림을 남기면 수금 인식이 새 영수증으로 읽어 수금이 두 번 잡힐 수 있음(아래 7절). 보낸 사실은 상담 기록으로 남김.
㉢보내기 전에 늘 미리 보기를 거칠지거침(고객에게 나가는 것이라 한 번 보고 누르시게).
㉣새 영수증이 폴더에 들어오면 알림이번엔 안 함 — 단추로만. 써 보시고 필요하면 「답하실 것」 카드에 「○○ 영수증 문자 보내기」로 더함.

7. 같이 보고 드릴 것 (고치지 않음, 확인 대상)

손으로 만드신 「전○○_현금영수증.png」(오늘 16:24)·「유○○_현금영수증.png」(11-17)가 PDF와 같은 폴더에 있습니다. 수금 인식은 같은 이름의 PDF·그림을 한 번에 읽으면 한 건으로 세지만, PDF를 먼저 읽고 그림이 나중에 들어오면 그림을 새 영수증으로 따로 셀 수 있습니다. 유○○ 님 수금이 두 줄로 들어갔는지 [확인 필요] — 만들 때 수금 기록을 열어 확인하고 결과를 보고 드리겠습니다.

8. 차례와 확인 방법

  1. 서버 사진 문자 함수 → 세무사님 휴대폰으로 시험 한 통(110원, 보내기 전 여쭘).
  2. 영수증 찾기·PDF → JPG(16개 PDF 모두 200KB 안·글자 읽히는지 그림으로 확인).
  3. 화면 단추·미리 보기 창 — 가짜 서버 사본으로 PC·폰 폭에서 실제 클릭.
  4. 넥스 [실행] 카드·이음매 줄.
  5. 커밋·배포는 세무사님 지시 때. 배포 뒤 운영에서 세무사님 휴대폰으로 한 통 더.
