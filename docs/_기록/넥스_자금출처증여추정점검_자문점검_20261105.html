계산기(calculate_property_acquisition_funds_gift_tax)를 네 갈래로 돌려 시행령 §34① 단서의 문턱(취득가액 20%와 2억 중 적은 금액)과 §55①3호 정액공제 3천만원, 합산배제를 손셈과 맞췄습니다. 모두 법대로였고 코드 변경은 없습니다. 연령·직업별 소액 취득 배제 기준(국세청 고시)이 도구에 없음을 판단거리로 남깁니다.

1. 사건 (시험용 가정)

  • 「구씨」(35세)가 2026-03-10 집 4억을 삼 — 입증 2.8억 / 3.3억. 28세 「구씨 동생」이 1.2억 집을 입증 없이 삼. 15억 취득·입증 12억(미입증 3억).

2. 법 (원문을 직접 읽음 — 상증법 20260102·시행령 20261001 시행판)

  • §45①: 직업·연령·소득·재산 상태로 자력 취득이 어렵고 대통령령 경우면 취득자금을 증여받은 것으로 추정. 시행령 §34①: 입증 금액(신고·과세 소득, 신고·과세 상속·수증 재산, 재산 처분 대가·부채로 직접 쓴 돈) 합계가 취득가액에 미달하는 경우 — 단, 미입증 금액이 취득가액 20%와 2억원 중 적은 금액에 미달하면 제외. §45③·시행령 §34②: 10년 안 취득자금 합계 5천만원 이상으로서 국세청장이 정하는 금액 이하면 적용 안 함. §47① 합산배제·§55①3호 3천만원 정액공제.

3. 도구가 놓치던 것

  • 없음 — ① 미입증 1.2억 ≥ 문턱 8천만 → 증여의제이익 1.2억 − 정액공제 3천만 = 과세표준 9천만, 납부 8,730,000(신고세액공제 3%) ② 미입증 7천만 < 8천만 → 과세 없음 ③ 1.2억 전액 미입증, 문턱 2,400만 → 과세표준 9천만 ④ 미입증 3억, 문턱 2억(20%=3억보다 적음) → 과세.
  • 국세청 고시 배제 기준(연령·직업·재산 상태별 소액 취득)은 도구가 일부러 넣지 않음(수시로 바뀌는 행정 기준) — ③처럼 28세 1.2억 주택은 고시 기준 안에 들 수도 있어 넥스가 따로 봐야 함.
