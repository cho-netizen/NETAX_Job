넥스 점검 216 — 「증자 이익의 증여(상증법 §39·시행령 §29) 계산기 — 다섯 갈래 산식·문턱과 주권상장법인등 단서(증자 후 시가와 견줌)」 자문점검 · 2026-11-05

계산기(calculate_capital_increase_gift_tax)를 열 갈래로 돌려 시행령 §29②1~5호·단서를 맞췄습니다. 비상장 산식·문턱은 모두 맞았고, 주권상장법인등이면 증자 후 1주당 평가가액과 견주는 단서(저가는 적은 값, 고가는 큰 값)가 없던 것을 현물출자 계산기와 같은 칸으로 더했습니다.

1. 사건 (시험용 가정)

  • 가족 법인(증자 전 10만 주, 1주당 평가 10만)이 신주 1만 주를 5만에 발행, 아버지가 전부 포기해 아들이 실권주 1만 주 배정. 견주기: 상장법인으로 증자 후 시가 8만·12만 / 실권주 미배정(2호) 차이 5%·50% / 고가 15만 배정·상장 시가 12만 / 고가 미배정 10% / 비주주 직접 배정 고가 / 증자 전·후 모두 0 이하.

2. 법 (원문을 직접 읽음 — 상증법 20260102·시행령 20261001 시행판)

  • §39①1호(저가 발행): 가. 실권주 배정 나. 실권주 미배정(특수관계인 인수) 다. 비주주 직접 배정 라. 균등 초과 배정 / 2호(고가 발행) 가~라 대칭 / 3호 전환주식. ②: 소액주주 2명 이상이면 1명으로 봄. 증여일(시행령 §29①): 상장법인 주주 배정은 권리락일, 전환주식은 전환일, 그 밖은 주식대금 납입일(신주인수권증서 교부일).
  • 시행령 §29②: 1호(가·다·라목) = (증자 후 1주당 가액 − 인수가액)×실권주·신주 수, 단서: 주권상장법인등은 증자 후 1주당 평가가액이 산식보다 적으면 그 가액. 2호(나목) = 균등 증자 기준 산식, 문턱 30% 또는 3억. 3호(고가 배정) = (인수가액 − 증자 후 가액)×실권주, 단서: 상장이면 평가가액이 산식보다 크면 그 가액. 4호(고가 미배정) 문턱 30%·3억, 5호(비주주·초과) 문턱 없음. 단서: 증자 전·후 1주당 가액이 모두 0 이하면 이익 없음.

3. 도구가 놓치던 것

  • 비상장 산식·문턱은 모두 맞음: 저가 배정 (95,455 − 5만)×1만 = 4억 5,455만 / 2호 5% 미달·50% 과세 / 고가 배정 (15만 − 104,545)×1만 / 4호 10% 미달 / 5호 문턱 없이 과세 / 둘 다 0 이하 → 0.
  • 주권상장법인등 단서가 없었다 — 상장법인이 증자 후 시가 8만인데 산식 95,455로 셈해 이익 4억 5,455만(법은 8만 → 3억). 고가도 시가 12만 > 산식 104,545이면 12만을 써야 하는데 산식으로 셈했다. 현물출자(§39의3)·합병(§38) 계산기는 10월·11-02에 같은 단서를 넣었는데 증자만 빠져 있었다.
