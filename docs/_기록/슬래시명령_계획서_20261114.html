  • 읽기: 로그인 뒤 넥스 대화창을 처음 열 때 한 번 서버에서 받아 기기에 사본을 둠. 다음부터는 사본을 먼저 쓰고 뒤에서 새로 받음(목록이 바로 뜨게). 로그인 전에는 서버를 부르지 않음(로그인 창이 안 뜨던 10-14 사고 규칙).
  • 기본판과 세무사님 판: 기본 명령은 화면 코드 안 기본판에 있고, 파일에는 세무사님이 고친 칸과 새로 만든 명령만 저장합니다. 그래서 나중에 Claude가 기본판에 명령을 더하거나 고쳐도 세무사님이 고친 것은 그대로 남습니다.
  • 저장: 설정에서 저장하면 서버가 파일에 쓰고 앞 판은 같은 폴더 _이전판에 남김. 두 기기에서 동시에 고치면 나중 저장이 앞 판을 덮지 않게, 서버가 판 시각을 견줘 「다른 기기에서 바뀜 — 다시 불러오기」를 띄움(넥스 대화 덮어쓰기 막기와 같은 방식).
  • 쓰임 기록: 명령을 쓸 때마다 서버 기록에 한 줄(번호·날짜·0원/유료). 설정 묶음을 열면 이것을 세어 보여 줌.
  • 더할 만한 후보: 유료 질문 기록 가운데 넥스 대화 질문에서 같은 꼴이 3번 넘게 나온 것(예: "보고서가 저장되지 않았다" 8번)을 설정 묶음 아래에 보여 줌. 지금 대화창 비용 표에 있는 「유료 AI로 간 질문」 목록을 넓힌 것입니다.
  • 서버에서 새로 하는 일: 명령표 읽기·쓰기 두 가지, 쓰임 한 줄 적기, 새 0원 명령에 서버 값이 필요하면 그 조회(만들 때 지금 서버 기능을 먼저 찾아 씀). 소통 이음매 점검표에 「넥스 명령이 순서 글과 함께 넥스에 닿는지」 한 줄.

3-7. 안전장치

  • GAS 명령은 보기·화면 열기만 합니다(지금 바로 처리와 같음). 값을 바꾸거나 지우거나 고객에게 보내는 일은 명령 하나로 바로 하지 않습니다. 바꾸는 일은 결과 안 단추를 세무사님이 눌러야 합니다(예: /폴더의 「다시 잇기」).
  • 겹침 막기: 이름·다른 이름·말로 하는 표현이 다른 명령과 겹치면 설정에서 저장을 막고 어느 명령과 겹치는지 보여 줌.
  • 판단 낱말 규칙 유지: 말로 하는 표현을 넓게 적어도 "왜 저장이 안 됐는지 검토해"처럼 판단을 구하는 말은 짐작하지 않고 넥스로 갑니다.
  • 순서 글은 원칙 아래: 넥스 명령의 순서 글은 마스터 프로필·공통원칙을 덮지 못합니다. 넥스에게 「아래 순서는 이 명령의 작업 순서이며 원칙과 어긋나면 원칙을 따른다」를 함께 붙입니다.
  • 파일이 깨지면: 명령표 파일을 못 읽으면 기본판으로 돌고, 설정 묶음에 「명령표를 읽지 못함」을 띄웁니다(소리 없이 빠지지 않게).

8. 순서

  1. 명령표·바로 처리 낱말 옮기기(화면 이름표를 지금 메뉴 이름으로)·입력칸 목록·보내기 가르기 (화면)
  2. 새 GAS 명령 4개(/저장확인·/폴더·/확인할것·/사건)·짧은 긍정 (화면, 이미 있는 서버 기능을 씀 — 없으면 만들 때 말씀드림)
  3. 넥스 명령 9개·말하기 「명령」 (화면)
  4. 설정 「넥스 명령」 묶음·명령표 저장 파일·쓰임 기록 (화면 + 서버 두 가지)
  5. 소통 이음매 한 줄·사용 설명서 (서버·화면)
  6. 화면 다시 조립·시험(9절)
  7. 커밋·배포 — 세무사님 지시가 있을 때

9. 확인 방법

  • 서버를 막은 가짜 서버 시험 사본에서 PC·태블릿·폰 크기마다 실제로 타이핑·클릭: / 목록·좁혀짐·↑↓·Enter·Tab·Esc·손가락·한글 조합 중 Enter.
  • 바로 처리가 지금 하던 12가지를 같은 말로 해 보고 결과가 그대로인지(옮긴 뒤 빠진 것 없음) 견줌. 지금 메뉴 이름("사건 목록 열어")도 알아듣는지 봄.
  • 이번 조사에서 뽑은 실제 말(저장·폴더·긍정·확인할 것)을 그대로 넣어 0원으로 가는지 봄.
  • 설정에서 넥스 명령 하나 더하기 → 대화창 목록에 뜸 → 끄기 → 사라짐 → 다시 켜기, 다른 기기 크기에서도 같은 표인지 봄.
  • 넥스 명령은 운영에서 처음 보는 가상사건으로 /검토서·/조서를 돌려 정식 이름·지침대로 저장되는지 봄(상한 5,000원, 끝나면 가상사건·고객·폴더 지움) — 유료라 세무사님 허락이 필요합니다.
