넥스 점검 231 — 「국외자산 양도소득세(소득세법 §118의2~§118의8) 계산기 — 5년 거주·250만 공제·기본세율·외화 환산 확인과 외국납부세액 「필요경비 산입 방법」(§118의6①2호) 잇기」 자문점검 · 2026-11-05

계산기(calculate_overseas_asset_transfer_tax, 다건 포함)를 일곱 갈래로 돌려 §118의2·§118의4~§118의8·시행령 §178의5를 맞췄습니다. 세액공제 방식·공제 한도·외화 환산·옛 한도 안내는 맞았으나, 필요경비 산입 방법을 고르면 세액공제만 0으로 하고 외국 세금을 필요경비로 빼지 않던 것을 단건·다건 계산기 모두 고쳤습니다.

1. 사건 (시험용 가정)

  • 5년 넘게 국내 거주한 사람이 미국 주택을 2026-05-01 10억에 양도(취득 6억·양도비 2천만), 미국에 양도세 3천만 납부. 견주기: 세액공제 방식 / 필요경비 산입 방식 / 5년 미만 거주 / 달러 금액 + 환율 / 외국세 2억(한도) / 2019년 양도 / 다건(필요경비 방식 건 + 공제 방식 건).

2. 법 (원문을 직접 읽음 — 소득세법 읽기용 판)

  • §118의2: 양도일까지 계속 5년 이상 국내 주소·거소를 둔 거주자의 국외 토지·건물·부동산 권리 등. §118의4: 필요경비 = 실지 취득가액(없으면 소재국 시가·보충) + 자본적지출 + 양도비. §118의5: §55① 기본세율. §118의6①: 외국에서 낸 양도소득세는 1호 세액공제(한도 = 산출세액 × 그 자산 소득금액 ÷ 그해 국외자산 소득금액) 또는 2호 필요경비 산입 방법 중 선택. §118의7: 연 250만 공제(국내분과 따로). §118의8: 장기보유특별공제 없음(단서). 시행령 §178의5: 외화는 받은·지출한 날 기준환율·재정환율.

3. 도구가 놓치던 것

  • 세액공제 방식 맞음: 차익 3.8억 − 250만 = 3.775억 → 기본세율 1억 2,506만 − 공제 3천만 → 9,506만 + 지방 950.6만 = 1억 456.6만 / 외국세 2억이면 한도 = 산출세액 / 5년 미만 → 대상 아님 / 70만$×1,400 − 50만$×1,200 = 3.8억 / 2019년은 옛 한도 안내.
  • 필요경비 산입 방법(expense)을 고르면 세액공제만 0으로 하고 외국세 3천만을 필요경비에서 빼지 않아 차익이 그대로 3.8억 — 법은 3.5억. 칸 설명이 「이미 필요경비에 포함해 입력했다면 선택」이라 넥스가 transferExpenses에 넣지 않으면 어느 방법을 골라도 공제 방식보다 세금이 많았다. 다건 계산기도 같았다.

4. 고친 것

  • gs-backend/manage/taxcalc-engine.html calculateOverseasAssetTransferTaxJS·calculateOverseasAssetTransferTaxMultiJS: expense면 foreignTaxPaidAmount를 양도차익에서 빼고 「외국납부세액_필요경비산입」으로 보여 줌.
