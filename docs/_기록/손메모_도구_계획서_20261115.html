1. 목적

세무사님 원문(11-15): "손 메모에 편집도구가 부족해 보인다" → "숨은도구를 모두 꺼내지 말고 유형별로 묶어서 꺼내고, 없는 도구는 모두 추가하면서 역시 유형별로 묶어 보자"

지금 손 메모의 도구 여섯 가지는 ✏️ 단추 하나에 숨어 있어 누를 때마다 다음 도구로 넘어갑니다. 이것을 종류별 묶음 단추로 꺼내고, 없는 도구를 더해 같은 묶음에 넣습니다. 편집 줄 모양(연한 바탕·단추 한 크기·왼쪽 고치는 도구 …… 오른쪽 보기 도구)은 어제 정하신 그대로 둡니다.

그림판은 「쪽마다 그림 한 장」 방식입니다. 그은 선을 하나씩 따로 기억하지 않습니다. 펜은 누르는 힘에 따라 굵기가 조금 바뀝니다. 저장하면 쪽마다 그림을 PDF로 묶습니다.

5. 정하실 것

무엇권장다른 길
㉠묶음 단추를 누르면단추 몸을 누르면 그 묶음에서 마지막에 쓴 도구를 바로 쥠, 오른쪽 ▾를 누르면 목록을 펼침 — 같은 도구를 다시 쓸 때 한 번에 됨누를 때마다 목록을 펼침(늘 두 번 누름)
㉡「한 획 통째로 지우기」 지우개이번에는 넣지 않음. 지금 그림판은 그은 선을 따로 기억하지 않는 「그림 한 장」 방식이라, 한 획을 골라 지우려면 그림판 바탕을 통째로 바꿔야 함(저장·되돌리기·쪽 넘기기를 다시 짜야 함). 대신 지우개 크기·영역 지우기·올가미 선택 후 지우기로그림판을 「선 하나하나 기억」 방식으로 바꾸고 넣기 — 일이 크고 지금 저장된 손글씨와 방식이 달라짐
㉢글자 상자·사진을 넣은 뒤놓기 전까지는 옮기기·고치기·크기 바꾸기, 「놓기」(또는 다른 도구를 쥐면) 뒤에는 그림에 붙음 — ㉡과 같은 까닭나중에도 다시 고칠 수 있게 — ㉡의 바탕 바꾸기가 먼저 필요

6. 만드는 순서 (확정 뒤)

  1. 손 편집 줄 원본(memo.html) — 묶음 단추·펼침 목록 틀, 있는 도구 여섯·배경·확대를 묶음으로 옮김(하는 일 그대로)
  2. 색·굵기 묶음(자주 쓰는 색·최근 색·세 굵기)
  3. 더할 도구 — 붓펜·지우개 크기·화살표·원·삼각형·반듯하게·네모/올가미 선택(옮기기·크기·복사·지우기)·글자 상자·사진 넣기·날짜 찍기·점 배경·배경 걷기·쪽 지우기/복사
  4. 모양(style.html) — 묶음 단추 ▾·펼침 목록·쥔 도구 눌린 모양, 폰에서 목록이 화면 안에
  5. 사용 설명서 손글씨 줄 고침
  6. 화면 다시 조립 → 가짜 서버 시험 사본

7. 확인 방법

  • 가짜 서버 사본에서 PC(1280)·태블릿(768·1024)·폰(375)으로, 도구마다 실제로 끌어 그리고 → 되돌리기 → 다시 → 쪽 넘겼다 돌아와도 남는지 → [저장] → 「일반메모로」로 PDF가 만들어지는지(넣은 글자·사진·도형이 PDF에 보이는지)
  • 묶음 단추: 몸 누르면 마지막 도구, ▾ 누르면 목록, 목록 밖을 누르면 닫힘, 쥔 도구가 눌린 모양
  • 폰 폭에서 손 편집 줄이 지금처럼 두 줄 안, 펼친 목록이 화면 밖으로 나가지 않는지(숫자로)
  • 떠 있는 ✍로 들어와 바로 쓰기, 글↔손 오가도 그림이 그대로
  • 화면만 바뀜 — 서버 고침 없음
