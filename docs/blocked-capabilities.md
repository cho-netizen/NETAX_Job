# 지금 job에서 막혀 있거나 비싼 기능 목록

세무사님 지시(2026-10-13): 문서 자동입력 같은 도구 기술이 매우 빠르게 발전하고 있다. 지금은 불가능하다가 나중에 가능해지는 것들을 모아 시스템을 개선해야 한다.

이 문서는 **새로 가능해진 기술(능력 정찰)과 대조할 기준표**다.
- job은 매주 밤 무료 공개 자료(릴리스 노트·변경 페이지·공공데이터포털 목록)를 모아 개선 후보 보고서(`_개선후보.json`)의 `capabilities` 항목에 넣는다.
- 주간 웹 Claude Code 루틴은 그 항목을 아래 표와 대조한다. 풀 수 있는 대안이 생겼으면 시범 구현 PR을 올리고, 풀지 못하면 "관찰"란에만 적는다.
- 고친 항목은 "상태"를 바꾸고 날짜와 커밋을 적는다. 새로 막힌 것을 발견하면 행을 추가한다.

원칙: 대안도 **토큰 0 또는 최소 비용**이어야 한다. 무료 범위·기기 안 AI·정부 무료 API가 우선이고, 유료면 비용을 PR에 적고 사람이 누를 때만 쓴다.

## 루틴이 `capabilities`를 볼 때
1. 각 신착 항목을 위 표의 "풀릴 수 있는 길"과 대조한다.
2. 관련 있으면 "관찰"란에 날짜와 근거(링크)를 적는다(문서만 고치는 PR이어도 됨).
3. 실제로 대안이 생겼으면 시범 구현 PR을 올린다. 무료 범위·한도·비용·개인정보(고객 자료가 외부 서비스로 나가는지)를 PR 본문에 적는다. 고객 자료가 무료 외부 AI로 나가는 대안은 쓰지 않는다.
4. 모델 ID가 없어졌다는 `tech` 경고는 최우선이다. 같은 등급의 새 모델로 바꾸는 PR을 올린다(MODEL_CONFIG·DEFAULT_MODEL·LIGHT_MODEL).
