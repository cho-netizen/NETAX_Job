# 쇼츠·블로그 콘텐츠 제작 파이프라인 — 설계 메모(구현 전)

세무사님 구상(2026-10-13): 보고서 모음으로 템플릿 피드백뿐 아니라 블로그 글을 쓰고, 나아가 블로그보다 설득력 있는 쇼츠를 만든다. 주특기가 다른 여러 AI(대본·그림·영상·목소리·자막·편집)가 필요하다.

이 문서는 설계 메모다. 구현은 별도 작업으로 하고, AI 연합체 명단(`Federation.js` AI_REGISTRY_)의 주특기 칸(이미지생성·영상생성·음성합성·자막·편집)에 후보를 올려 둔다.

## 원칙
- **고객 정보 0**: 원본 보고서에서 이름·금액·주소를 일반화한 "교훈 중심 사례"만 쓴다(지금 블로그 글감 만들기와 같은 원칙). 무료 웹 AI·무료 API로 보내는 글은 이 일반화본만.
- **비용**: 대본·구성은 기존 블로그 글감(LIGHT_MODEL) 확장. 그림·영상·목소리는 무료 범위 우선, 유료면 버튼을 누를 때만, 비용 표시.
- **사람 확인**: 공개 전 세무사님이 대본·영상을 확인한 뒤에만 올린다(자동 게시 없음).
- **약관**: 무료 웹 AI(B 등급)는 자동화 금지 → 생성 화면을 열어 주고 세무사님이 직접 만들어 저장(수동).

## 단계(후보)
| 단계 | 할 일 | 후보(무료 우선) | 비고 |
|---|---|---|---|
| 1 소재 | 보고서 모음에서 쟁점 사례 고르기 | GAS(규칙) | 최근 발행·반응 좋은 주제 |
| 2 대본 | 30~60초 대본(훅 3초·쟁점·결론·주의 문구) | Claude Haiku/Sonnet(유료, 버튼) 또는 A 등급 무료 API(일반화본만) | 블로그 글감 함수 확장 |
| 3 장면 | 장면별 문구·그림 설명 | 같은 AI | 표·수치는 GAS가 그림(차트)으로 |
| 4 그림 | 장면 그림·썸네일 | 웹 AI 이미지 생성(수동), 무료 스톡 | 저작권·초상권 확인 |
| 5 목소리 | 내레이션 | Google Cloud TTS 무료 범위(A), 크롬 음성(수동) | 한국어 음성 품질 비교 |
| 6 자막 | 대본 → 자막 파일(SRT) | GAS(규칙, 대본 그대로) | 0원 |
| 7 편집 | 그림+목소리+자막 합치기 | 무료 편집기(수동), 서버 렌더링은 비용 검토 | GAS로 영상 합성은 어려움 |
| 8 게시 | 유튜브 쇼츠·네이버 클립 | 세무사님 수동 게시 | 블로그 자동발행과 같은 확인 원칙 |

## 다음 결정이 필요한 것
- 목소리: 세무사님 목소리(직접 녹음) vs 합성 음성.
- 편집을 어디서: 무료 편집기 수동 vs 유료 렌더링 서비스.
- 첫 시범: 보고서 1건 → 대본·자막까지만 자동(0원~수십 원), 나머지 수동으로 한 편 만들어 보기.
