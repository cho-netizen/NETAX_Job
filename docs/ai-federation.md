# AI 연합체 · AI 자문단 · 개발자↔사용자 소통

세무사님 구상(2026-10-13):
- "다양한 AI가 버전업되거나 새로 생겨나고 있다. 이런 모든 AI를 무료 계정으로라도 망라해 적재적소에 활용하는 AI 연합체."
- "job 성능개선을 위해 꾸준히 여러 AI들로부터 관련 기술 정보를 습득하고 시스템에 적용해 나가는 과정."

코드: `gs-backend/Federation.js`(명단·배차·다수결·자문단·소통·2중 검증). 화면은 설정 🐞 카드, 대시보드 "AI 연합체·소통" 카드, 세액계산 🔍 2중 검증 버튼.

## 1. 팀장
| 팀 | 언제 | 팀장 | 이유 |
|---|---|---|---|
| 운영팀 | 세무사님이 job을 쓰는 순간(실시간) | **GAS** | 배차·예산·고객자료 차단·기록은 판단이 아니라 규칙이다. 0원이고 매번 똑같이 지킨다. |
| 작업반장(예외) | 🧠 전략 검토 등 열린 과제 | Claude Opus/Sonnet | GAS가 예산 상한(배차표 strategy.maxKrw)·도구·자료 범위를 넘겨주고 감독한다. |
| 정비팀 | 시스템 개선(비동기, 주 1회) | **웹 Claude Code 루틴** | 판단·코드 작성이 필요하고 구독 요금이라 job 비용 0원. |

## 2. 명단(registry) 등급
- **A 무료 공식 API** — Gemini API 무료 등급·Groq·OpenRouter 무료 모델·Mistral·Hugging Face. GAS가 공식 API로 직접 호출한다. **고객 자료 금지**(무료 등급은 입력이 서비스 개선에 쓰일 수 있음). 키는 세무사님이 발급해 설정 🐞 카드 🔑에 넣는다. 키가 없으면 "대기".
- **B 무료 웹 계정** — ChatGPT·Gemini·Claude·Copilot·Perplexity·DeepSeek·Grok·클로바X. **수동 모드만**: job이 질문을 복사하고 사이트를 열어 주면 세무사님이 보내고, 답을 복사해 job에 붙여 넣는다. 고객 자료 금지.
- **C 유료 API·기기 안 AI** — Claude(Sonnet·Haiku·Opus)·Gemini 유료 API·크롬 내장 Gemini Nano. **고객 자료는 여기만**(유료 API는 학습 미사용 약관, 기기 안 AI는 PC 밖으로 안 나감).

주특기 칸: 세법판단·전략·문서작성·요약·분류추출·번역·일반지식·코딩·기술·웹검색·긴문서 + **콘텐츠 제작 계열(이미지생성·영상생성·음성합성·자막·편집)** — 블로그·쇼츠 구상용(쇼츠 파이프라인은 `docs/shorts-pipeline.md` 설계 메모).

### 무료 웹 AI 자동화를 하지 않는 근거(2026-10-13 약관 확인)
| 서비스 | 약관 요지 |
|---|---|
| ChatGPT(OpenAI) | 데이터나 Output을 자동·프로그램으로 추출 금지(Terms of Use "What you cannot do") |
| Claude(Anthropic 소비자) | API 키로 접속하거나 명시 허용된 경우 외 봇·스크립트 등 자동·비인간 방식 접속 금지 |
| Gemini(구글) | robots.txt 등 기계판독 지시를 어기는 자동 접근 금지 — gemini.google.com robots.txt가 /app·/chat 차단 |
| Copilot(마이크로소프트 서비스 약관) | 명시 허용 없이 웹 스크래핑·데이터 추출 금지 |
| Perplexity | 봇·자동화 도구·로봇·크롤러로 수집 금지 |
| DeepSeek | 로봇·스파이더 등 자동 수단으로 내용 복제 금지 |
| Grok(xAI) | 이용정책상 허가 없는 봇·스크립트 자동 접속 금지(원문 재확인 필요) |
| 클로바X(네이버) | 자동화 수단 접근 제한(원문 재확인 필요) — 확인 전까지 수동 |

→ 질문을 자동으로 넣거나 답을 자동으로 가져가는 방식은 쓰지 않는다. **⚠ 기존 🔮 제미니 자동 경로(NX 커넥터 content-gemini.js)도 같은 문제 소지가 있다 — 세무사님 결정 대기(코드는 그대로 둠).**

## 3. 배차(GAS) 규칙
고객 자료 여부 → 무료 가능 여부 → 주특기 → 오늘 남은 무료 한도 순서로 고르고, 실패하거나 한도가 차면 다음 후보로 넘어간다. 사용량은 날짜별로 기록한다(`AI_USE_yyyyMMdd`). 배차표는 `AI_DISPATCH_TABLE_`(작업 종류 → 순서·예산 상한·고객자료 여부).

## 4. 다수결 교차검증
고객 정보 없는 일반 질문을 A 등급 3곳에 동시에 묻고 "결론:" 줄을 비교한다(숫자가 다르면 다른 결론). 2곳 이상 같으면 채택, 아니면 "유료 AI나 법령 원문으로 확인 권장". 결과에 출처·합의 수를 표시한다. 주민번호·전화·계좌·상세주소 모양이 있으면 기계적으로 막는다.

## 5. AI 자문단 순환(주 1회, 0원)
1. **질문 생성**(GAS): `docs/blocked-capabilities.md`의 막힌·비싼 기능 + 개선 후보 보고서(반복 오류·유료 비용) + 기본 정찰 질문 → 최대 5문항. 고객 정보 차단.
2. **수집**: A 등급 무료 API에 자동으로(월요일 야간). B 등급은 설정 🐞 카드 🧑‍🏫에서 수동(질문 복사·사이트 열기·답 붙여넣기).
3. **정리**: `_AI자문.json`에 질문별 답을 묶고, 여러 AI가 비슷하게 낸 제안은 "공통", 하나만 낸 제안은 "단독"으로 표시 → 개선 후보 보고서 `ai_advice`.
4. **검증·적용(주간 루틴)**: 공통 제안부터 공식 문서로 사실 확인 → job 적용 가능성 시험 → PR. 확인 안 되면 기각 사유를 적는다.
5. **AI 성적표**: 세무사님이 채택·기각을 누르면 AI별로 기록 → 질문 배분 조정, 새 AI는 시험 기간 후 편입.

### 신규 AI 편입 절차
환경변화 세션의 `capabilities`에 새 AI·새 버전이 잡히면, 루틴은 고정 시험 세트(고객 정보 없음: 세법 일반지식 5문항·한국어 문서 요약 1건·숫자 추출 1건)로 측정해 `Federation.js`의 `AI_REGISTRY_`에 올리는 PR을 만든다. 무료 범위·한도·약관(자동화 허용 여부)을 PR에 적는다.

## 6. 개발자(웹 Claude Code) ↔ 사용자(job·세무사님) 소통
- **최근 바뀐 기능**: 📥 반영·PC 배포(mark-deployed) 때 새 커밋 제목을 30일치 기록 → job AI 지시문에 짧게, 대시보드 "새 기능"에 표시.
- **요청 수명주기**: 개선요구사항마다 번호(R…)·상태(접수 → 반영됨 → 확인완료/재오픈). **루틴은 커밋·PR 제목에 `[요청#R…]`을 넣는다** — 📥 반영 때 job이 자동으로 "반영됨"으로 바꾸고 세무사님에게 "확인해 주세요"를 띄운다. 재오픈은 다음 보고서에 다시 실린다.
- **기능 부족 신고**: job AI가 할 수 없는 일을 만나면 `report_capability_gap` 도구로 "원한 것·막힌 이유·필요한 도구"를 남긴다(고객 값 제외) → 보고서 `gaps`.
- **개발자 질문**: 루틴은 묻고 싶은 것을 `docs/dev-questions.md`에 `## Q-YYYYMMDD-n 제목` 블록으로 남긴다. job이 설정 🐞 카드에 보여 주고, 세무사님 답이 다음 보고서 `answers`에 실린다. 답을 반영했으면 그 블록을 지운다.
- **오류 재현 묶음**: 화면 오류 기록에 최근 서버 요청 8개(이름·성공/실패·시간만, 입력값 없음)와 화면 크기를 붙인다.
- **긴급**: 요청 글에 "긴급·급함·당장"이 있으면 대시보드에서 "지금 개발자 부르기(🛠)"를 강조한다.
