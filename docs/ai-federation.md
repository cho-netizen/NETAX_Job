# AI 회의 · 개발자↔사용자 소통

2026-10-19 재편. 예전 "AI 연합체·AI 자문단"을 **회의 틀 하나**로 바꾸고, 돌지 않던 것은 숨기지 않고 지웠다.
세무사님 원문: "이 모양으로 일단 ai연합 법령검토기능을 구현한다면 설정탭의 ai연합은 어떻게 할 것인가? 시스템업그레이드 목적에 부합하는 대한을 찾아야 하나?" / "작동하지 않는 것을 숨김다고? 삭제가 아니고?" / "이 방향으로 수정하자"

코드: `gs-backend/Federation.js`(명단·배차표·위원 묻기·판단 대기 파일·소통·세액 2중 검증). 화면: 설정 🤝 **AI 회의 · 개발자 소통** 카드, ⚖️ 법령정보 → 📜 법령 탭 **🤝 판단 대기**(회의 기록), 회의 사이드바(앱 전용 `app-only/multiai.html`·`judgewait.html`), 대시보드 "새 기능·개발자 소통·AI 회의" 카드, 세액계산 🔍 2중 검증.

## 1. 회의 틀 — 안건 두 종류
| 안건 | 무엇 | 위원 | 회장(결론) | 결론이 가는 곳 | 세무사님께 올라오는 것 |
|---|---|---|---|---|---|
| ⚖️ 법령 | 판단 대기(드라이브 `업무관리자/법령/_판단대기.json`, 만듦: netax-inventory/maps/법령도구/판단대기_만들기.js) | Gemini API(무료 등급) — OpenRouter 키가 들어오면 함께 | Claude(조정 세션) | 판단 대기 파일의 결정(누가 '회장(Claude)') — 엔진은 자동으로 안 고치고, 결정 목록을 조정·서식 세션이 보고 고침 | 회장이 결론을 못 낸 것(결정 '보류' = 🙋 결정 필요) |
| 🛠 시스템 | 개선 후보 보고서(반복 오류·유료 비용·막힌 기능·요청) + 개정 감시의 기술 변화 | Gemini API(무료 등급) | 주간 정비 루틴(웹 Claude Code) | 고침 작업(PR) | 결론 안 난 것·돈 드는 결정(`docs/dev-questions.md` → ❓ 개발자 질문) |

- 근거 확인(법령 안건): 위원 답의 근거 조문은 정비본으로, 판례·심판례 번호는 job 예규판례 검색(`law_search_precedent`)으로 **법제처에 실제로 있는지** 확인한다(✔ 있음 / ⚠ 못 찾음 — 지어낸 근거일 수 있음 / ? 국세청 예규처럼 법제처에 없는 종류). "있다"는 "관련 있다"가 아니므로 첨부는 사람이(또는 회장이) 고른다.
- 고객 정보는 위원에게 보내지 않는다 — 서버 `aiAskSlots_`가 `aiLooksClientData_`로 막는다(법령 질문지는 조문 원문 부분을 주민번호·전화·계좌 꼴만 검사).
- 회의 기록 저장(서버 동작, 이름·형식 고정 — 조정 세션이 씀):
  - `ai_judge_get` — 판단 대기 파일 전체
  - `ai_judge_save {id, answer:{ai,name,text,결론,방식}}` — 위원 답(답[ai]). 비교표 같은 회의 메모는 `_`로 시작하는 키로
  - `ai_judge_save {id, check:{ai, 근거}}` — 근거 실재 확인 결과
  - `ai_judge_save {id, decision:{선택,내용,메모,다수,근거,누가}, attach:[…]}` — 결정. **회장 결론은 `누가: '회장(Claude)'`**, 결론을 못 내면 `선택: '보류'` → 🙋 세무사님 결정 필요. 화면에서 세무사님이 고르면 누가 '세무사님'
  - `ai_ask_slots {ids, head, law}` — 위원에게 묻기(ids: 'gemini-paid'·'openrouter')

## 2. 명단(`AI_REGISTRY_`)
- **위원(무료 등급, 고객 자료 금지)**: `gemini-paid` = **Gemini API(무료 등급)** — 세무사님이 Google AI Studio에서 받은 키(`GEMINI_API_KEY`). id는 회의 기록·호출이 이 이름을 써서 그대로 둠(예전 표시 "Gemini(유료 API)"는 잘못이었음). `openrouter` = 키(`OPENROUTER_API_KEY`, 설정 🤝 → 👥 위원 상태에서 넣음)를 넣으면 위원이 늘어나는 자리 하나.
- **Claude API(유료, 고객 자료 허용)**: Sonnet·Haiku·Opus — AI 탭·전략 검토·보고서·세액 2중 검증 등 기존 배차.
- 지운 것(2026-10-19): 무료 AI 3곳 다수결(🗳·`ai_consensus`), AI 자문단 자동 수집·웹 AI 수동 붙여넣기(`ai_advice_*` — 기록 파일 `_AI자문.json`은 남김), 웹 AI 8곳(B 등급) 명단과 사이드바 "복사·열기·붙여넣기" 칸, Claude·Gemini 유료 칸 토글, 키 없는 무료 칸(gemini-free·groq·mistral·hf)과 대기 항목(google-tts·chrome-nano).

## 3. 배차표(`AI_DISPATCH_TABLE_`) — 실제로 도는 줄만
AI 회의(법령·시스템), 세무 쟁점 판단, 🧠 전략 검토, 보고서 판단 문단, 보고서 맞춤법, 세액 2중 검증. 사용량은 날짜별로 기록한다(`AI_USE_yyyyMMdd`), 위원 키·모델 상태는 새벽 5시 점검(`aiFederationNightly` — 트리거 이름은 운영에 걸려 있어 그대로, 개선 후보 보고서도 이때 다시 만듦).

## 4. 웹 AI 자동 조작을 하지 않는 근거(2026-10-13 약관 확인, 2026-10-19 Claude Code 권한 검사기도 막음)
ChatGPT·Claude(소비자)·Gemini(웹)·Copilot·Perplexity·DeepSeek·Grok·클로바X 약관은 자동 질의·답 수집을 막는다. 위원은 공식 API(Gemini API·OpenRouter)로만 부른다. 기존 🔮 제미니(NX 커넥터가 세무사님 제미니 화면에 묻기)는 AI 탭 기능으로 남아 있고 회의 위원은 아니다.

## 5. 개발자(웹 Claude Code) ↔ 사용자(job·세무사님) 소통
- **최근 바뀐 기능**: 📥 반영·PC 배포(mark-deployed) 때 새 커밋 제목을 30일치 기록 → job AI 지시문에 짧게, 대시보드 "새 기능"에 표시.
- **요청 수명주기**: 개선요구사항마다 번호(R…)·상태(접수 → 반영됨 → 확인완료/재오픈). **루틴은 커밋·PR 제목에 `[요청#R…]`을 넣는다** — 📥 반영 때 job이 자동으로 "반영됨"으로 바꾸고 세무사님에게 "확인해 주세요"를 띄운다. 재오픈은 다음 보고서에 다시 실린다.
- **기능 부족 신고**: job AI가 할 수 없는 일을 만나면 `report_capability_gap` 도구로 "원한 것·막힌 이유·필요한 도구"를 남긴다(고객 값 제외) → 보고서 `gaps`.
- **개발자 질문**: 루틴은 묻고 싶은 것을 `docs/dev-questions.md`에 `## Q-YYYYMMDD-n 제목` 블록으로 남긴다. job이 설정 🤝 카드 ❓ 개발자 질문에 보여 주고, 세무사님 답이 다음 보고서 `answers`에 실린다. 답을 반영했으면 그 블록을 지운다.
- **오류 재현 묶음**: 화면 오류 기록에 최근 서버 요청 8개(이름·성공/실패·시간만, 입력값 없음)와 화면 크기를 붙인다.
- **긴급**: 요청 글에 "긴급·급함·당장"이 있으면 대시보드에서 "지금 개발자 부르기(🛠)"를 강조한다.
