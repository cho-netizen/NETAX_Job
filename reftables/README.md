# 조견표·서식 칸 지도 자료 (reftables/)

법령정보 탭([📄 서식][📋 조견표])이 쓰는 자료입니다. 이 폴더의 JSON을 고친 뒤 `node tools/build-reftables.js` → `node tools/build-app.js`를 돌리면 화면 파일(gs-backend/manage/lawsearch.html)에 들어갑니다(새 서버 파일 없음 — 📥 반영 가능). 초안은 netax-inventory/maps/조견표/에서 만들고 원문 대조가 끝나면 여기로 옮깁니다. 설계: netax-inventory/maps/설계_조견표체계.md

{
  "서식번호": "소득세법 시행규칙 [별지 제84호서식 부표1]", "이름": "양도소득금액 계산명세서", "서식판": "개정 시행일",
  "출처": [{ "이름": "…", "주소": "…" }], "상태": "초안",
  "칸": [{ "칸": "⑪", "이름": "서식 글자 그대로", "작성방법": "작성방법 요지(짧은 인용+쉬운 말)", "계산": "예: ⑪ = ⑨ − ⑩ (칸끼리)",
          "근거조문": ["소득세법 §95①"], "계산기칸": ["엔진 입력·결과 이름(예: 결과 '양도차익')"], "조견표": ["2부-03"],
          "인쇄": "인쇄 함수에서 이 칸을 그리는 곳(함수명·줄 이름)", "확인": "원문 대조됨 | 확인 필요(이유)" }],
  "확인필요": ["…"]
}

## 규칙(모든 작업자)
- 출처는 공식만: 국가법령정보센터(law.go.kr)·부처 공고/고시·관보·국세청 서식/누리집. **기사·블로그 금지.** 해설서·요약 자료는 "대조"에만.
- 원문으로 확인 못 한 값은 "행"에 넣지 말고 "확인필요"에. 못 찾았다고 "없다"로 결론 내지 말 것.
- 모든 글은 한국어·쉬운 말. 시각은 `date` 출력으로.
- 세무사님 확인은 화면의 [이 표 확인] 단추로 남깁니다(Code.js reftable_review_*, 기록만). 확인 전에는 계산·판정에 쓰지 않습니다.
