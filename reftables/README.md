# 조견표·서식 칸 지도 자료 (reftables/)

법령정보 탭([📄 서식][📋 조견표])이 쓰는 자료입니다. 이 폴더의 JSON을 고친 뒤 `node tools/build-reftables.js` → `node tools/build-app.js`를 돌리면 화면 파일(gs-backend/manage/lawsearch.html)에 들어갑니다(새 서버 파일 없음 — 📥 반영 가능). 초안은 netax-inventory/maps/조견표/에서 만들고 원문 대조가 끝나면 여기로 옮깁니다. 설계: netax-inventory/maps/설계_조견표체계.md

## 서식 사전 전체 목록 — `_서식목록.json`
- 법령 시행규칙 별지 기준 서식 144종(지방세 신고서 제외). 법령정보 › 서식 탭이 이 목록을 세목(양도·상속·증여·공통)별로 보여 줍니다(`LSI_FORM_CATALOG_`).
- '_'로 시작하는 파일은 조견표가 아니라서 `build-reftables.js`가 조견표로 읽지 않습니다.
- 원본 PDF는 드라이브 `업무관리자\서식\법제처 원본(PDF)\<세목>`에 있습니다(목록은 그 폴더의 `_목록.md`). 법제처는 본표와 부표를 한 파일(묶음)로 올립니다.

## 위치판 — `위치판/서식위치_<짧은이름>.json`
- 법정서식 원본 PDF 위에 값을 올려 찍을 자리(쪽·x·y·w·h, PDF 점 단위, 위에서 잰 y)입니다. `원본.파일`은 드라이브 법제처 원본(PDF)의 묶음 PDF이고, `원본.md5`로 같은 파일인지 확인합니다.
- 칸 번호는 서식의 동그라미 번호 그대로입니다(칸 해설 `서식_*.json`과 같은 번호). 서식이 개정되면 새 개정일 원본으로 다시 잽니다.
- 아직 화면·서버에 넣지 않습니다(세액인쇄의 원본 모양 출력을 붙일 때 앱 자료로만 넣음 — 서버 10MB 한도).

## 규칙(모든 작업자)
- 출처는 공식만: 국가법령정보센터(law.go.kr)·부처 공고/고시·관보·국세청 서식/누리집. **기사·블로그 금지.** 해설서·요약 자료는 "대조"에만.
- 원문으로 확인 못 한 값은 "행"에 넣지 말고 "확인필요"에. 못 찾았다고 "없다"로 결론 내지 말 것.
- 모든 글은 한국어·쉬운 말. 시각은 `date` 출력으로.
- 세무사님 확인은 화면의 [이 표 확인] 단추로 남깁니다(Code.js reftable_review_*, 기록만). 확인 전에는 계산·판정에 쓰지 않습니다.
